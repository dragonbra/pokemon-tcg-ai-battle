Mask、label 与 STOP

padding 不参与 attention 或 loss

entity_mask [B,N]

标记真实 entity token；Transformer 的 CLS 始终有效，padding entity 被 src_key_padding_mask 屏蔽。

option_mask [B,M]

标记真实合法 option；pointer 还会屏蔽本序列中已经选过的 option，禁止重复选择。

targets [B,T]

专家选择的 option index 序列，末尾追加当前 batch 的 option_count 作为 STOP class；padding 为 -100。

min_count [B]

来自 select.minCount。解码步数未达到它以前，STOP logit 被硬 mask。

max_count [B]

来自 select.maxCount。teacher-forcing loss 不需要它；live greedy pointer 达到该步数时强制结束，避免返回超长动作。

03 / Architecture

实体编码，再做自回归选择

模型参数为 7,154,562，FP32 权重约 27.29 MiB。state encoder 和 option encoder 共享 card embedding；option 通过 entity reference 读取编码后的来源与目标表示。

State encoder

全局 4 路 embedding + 12 维数值 MLP 注入 CLS；entity 的 7 路 embedding + 5 维数值 MLP 形成 token。4 层、8 heads、FFN 960 的 pre-norm Transformer 编码联合序列。

Option encoder

12 个 option 字段求和，并 gather source / target entity token；随后以 option 为 query 对完整 state sequence 做 8-head cross-attention，再通过 2× hidden FFN。

Pointer decoder

CLS 初始化 320 维 GRU hidden。每一步对尚未选择的 options 计算 scaled dot-product pointer logit，同时计算 STOP logit；teacher forcing 用专家上一选择更新 GRU。

state, entities = Transformer([CLS(global); entity_tokens]) options = FFN(option_tokens + CrossAttention(option_tokens, [state; entities])) h_0 = tanh(W_init · state) logit(option_i, t) = <W_q h_t, W_k option_i> / sqrt(320) + bias(option_i) logit(STOP, t) = MLP_stop(h_t), masked while t < min_count h_(t+1) = GRU(selected_option_t, h_t) L_BC = CrossEntropy(pointer_logits, target_sequence, ignore_index=-100) # no category feature · no reward weight · no value head · no PPO objective

04 / Controlled comparison

与现有 universal BC 的区别

这不是对 0008/0009 baseline 的原地升级。0010 是独立项目，目标是先忠实复刻 notebook，再以同一冻结 corpus 做可比较评测。

维度0010 · ID-only pointer现有 universal BC / 0009
数据身份同一 Yushin Ito winner-only corpus、split、decision 与 label。同一 corpus；0009 另有 reward annotations 用于 weighted BC。
牌表示card ID + owner / zone / slot / parent；无官方 CSV metadata。结构化 card metadata、deck、entity、history、expert 等多路特征。
状态序列动态公开 entity sequence，最多 192。固定 state / cards / deck / entities / history 张量。
动作建模GRU 自回归 pointer；显式 STOP；有序多选序列。候选 score + count head；单选 CE，多/空选 BCE。
参数规模7.15M · d320 · L4 · 8 heads。当前 V4 约 3.54M · d192 · L2。
训练目标未加权 token CE，最低 validation token loss 选 checkpoint。baseline 为纯 BC；0009 可用轨迹 reward 权重调整 BC 样本关注度。
当前结论模型/codec 与冻结 reference 一致；V1 暴露空 entity collate 缺陷后保留失败记录，正式 V2 待训练与官方评测。已有离线曲线和官方 engine 固定池结果。
研究纪律

首次 V1 不开启 category、card metadata、deck/expert conditioning 或 reward weighting，也不从 0008/0009 checkpoint warm-start。只有完成 V1 的离线选择、标准 package 导出和官方 engine 固定池评测后，才能讨论哪套输入/模型更强。
