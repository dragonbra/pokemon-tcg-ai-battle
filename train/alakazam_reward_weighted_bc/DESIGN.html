准备探索哪些开关

每次训练只由一个 JSON config 决定。所有开关组合必须使用新的 V<n>_<tag>，不得覆盖结果，也不得根据 test 或正式 Evaluation 在同一版本内反复调参。

Feature

Reward

逐项 reward component

terminal、setup、Dunsparce bridge、Prize 推进、Post-KO relay、弃牌恢复 miss、回合数均可独立启停、设权重与 clip。

components[*].enabled
Weighting

模仿样本权重

uniform 是纯 BC 对照；linear 和 exponential 根据 detached advantage 调整专家样本关注度。

3 modes
Baseline

Advantage baseline

zero、训练集 reward 均值或当前 value 预测。value baseline 始终 detach，不允许通过权重路径反向传播。

zero / mean / value
Value

Value loss 与 warm-up

可重置 value 最终输出，可只训练 value head 若干 epoch，再打开 policy/count 联合训练。

reset / warm-up / coefficient
Safety

权重和 reward 护栏

组合 reward 可裁剪；样本权重必须非负并限制 min/max，同时记录 effective sample ratio，防止少数样本垄断梯度。

clip + ESS audit

02 / Reward semantics

每个指标如何进入训练

annotator 保存“原始事实信号”，config 再决定权重。事实、奖励和最终评测三层分开，避免某次权重选择改写历史 replay 的语义。

raw component:       f_j(record)
combined reward:     r = clip(Σ enabled_j α_j · f_j)
detached advantage:  A = r - baseline

uniform:             w = 1
linear:              w = clip(1 + scale · A, w_min, w_max)
exponential:         w = clip(exp(A / temperature), w_min, w_max)

L_imitation = weighted_mean(L_policy + L_count, w)
L_value     = SmoothL1(value, r)
L_total     = c_policy·L_policy + c_count·L_count + c_value·L_value

Terminal outcome

原始值胜 +1、负 −1、平 0，始终从 learner/expert 视角。
作用提高胜局专家动作的相对权重，降低负局动作的相对权重；也可作为 value target。
风险整局复制到每个 decision，credit 很粗，因此必须保留纯 BC 和 terminal-only 对照。

第二回合 Powerful Hand setup

触发按实际先后手把第二己方回合映射到 engine turn 3/4，并检查是否提交 attackId=1072。
原始值第二回合窗口内的 setup decision：成功 +1，失败 −1；窗口外为 0。
含义让第一、第二回合的搜索、进化、附能和过牌动作共同关注早期攻击闭环。

Dunsparce 第一回合铺场

机会开局 Active Dunsparce，手牌与场上均没有 Abra。
原始值第一己方回合结束前 Bench 出现 Abra：+1；没有建立底座：−1。
作用单独判断 Poffin、Poké Pad、Dawn 或过牌是否完成了下一回合的必要准备。

Dunsparce 第二回合完整执行

前提第二回合起始有 Bench Abra，手里同时有 Dudunsparce、Rare Candy、Alakazam 和 Psychic Energy。
成功有序观察到 Active Dudunsparce → Retreat 后 Active Abra → Active Alakazam → Psychic Energy → Powerful Hand。
原始值完整闭环 +1；机会出现但闭环失败 −1；非机会样本 0。

Post-KO relay

机会确认场上的 Alakazam 因伤害从 Active/Bench 进入弃牌区。
原始值下一己方回合另一只 Active Alakazam 提交攻击：+1；否则 −1。
诊断失败再分 field route miss、recoverable discard miss、手牌路线未闭合、牌库仍有资源和彻底无资源。

攻击没有推进 Prize

事实对每次攻击比较攻击前后己方剩余 Prize；保存 Prize delta 是否可确认。
信号attack_prize_delta 可正奖励；已解析但 delta≤0 的攻击记为 non-prize penalty，Powerful Hand 另有子项。
边界未解析或 Prize 不可确认时不猜测，不把未知样本算作失败。

可恢复的弃牌区接力 miss

触发Post-KO 接力失败，同时弃牌区可见 Abra/Kadabra/Alakazam 资源。
原始值发生为 1；配置使用负权重形成惩罚。
边界这是“存在恢复线索”的 proxy，不声称某个具体 Stretcher/Lana 动作一定合法或最优。

对局回合数

原始值整局最大 engine turn，保持原始数值，不在 annotator 内写死 5/6 回合阈值。
用法配置可给很小的负权重，观察快攻节奏；必须与 terminal outcome 一起消融。
风险单独最小化回合会奖励快速输掉，因此永远不能脱离胜负与 correctness 护栏。

严格 Dunsparce bridge 证据链

开局 Active Dunsparce，起手与场上没有 Abra。
第一己方回合通过合法搜索/过牌把 Abra 放到 Bench。
第二己方回合起始满足 Dudunsparce + Rare Candy + Alakazam + Psychic Energy。
Dunsparce 进化后，观测到 Active Dudunsparce。
完成 Retreat，观测到 Active Abra 且本回合 retreated flag 为真。
Abra 进化为 Active Alakazam，Active 最终持有 Psychic Energy。
提交 Powerful Hand。所有里程碑有序出现才记完整成功。

05 / Decision protocol

如何综合判断，而不是只看一个数字

过程奖励是诊断与优化假设，不能越过官方真实对局的结果和正确性护栏。任何“更快”“接力更高”都不能抵消 engine error、非法动作或明显胜率回归。

G0 · Correctnesscompleted、error、unfinished、合法动作。未通过立即停止。
G1 · Outcome总体与先后手胜率；固定 Evaluation 是权威能力证据。
G2 · Target metrics二回合 PH、严格 bridge、Post-KO relay、攻击质量、平均回合。
G3 · Training healthvalidation imitation、value MAE、权重范围、ESS、梯度与稳定性。
建议判断顺序：先 G0，再 G1；只有结果护栏没有回归时，才使用 G2 判断某个 reward 是否真正改善目标行为。G3 负责解释训练是否健康，不用于直接宣称策略更强。组合实验只允许使用已经在单项消融中通过护栏的组件。
