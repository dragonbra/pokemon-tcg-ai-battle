当前合同

Foundation

严格绑定 0019 Epoch 13，17,756,162 参数，SHA-256 da9b13d6…e5bb；source_id 永远为 0，Encoder 长期冻结。

48 Frozen

每套 exact deck 都有 Foundation decoder 质量锚点。训练期间永不更新，用于固定 greedy 回归评测。

48 Live

每套拥有独立 Decoder/Value model-only 资产。首个版本只更新 dragapult_ex_001；其余 47 套保持 update 0。

Official engine

每局在隔离 worker 中执行未修改 official runtime。CPU 负责状态转移，双方策略动作由父进程集中 GPU 推理。

运行拓扑

isolated official-engine workers
    │ focal + opponent observation requests (0.5 ms coalesce)
    ▼
one resident GPU service
    shared frozen Encoder ── one mixed batched forward
       ├── focal Decoder/Value: stochastic behavior action
       └── Foundation Decoder: greedy Frozen/Live-view opponent action
    │ legal ordered action response
    ▼
terminal trajectories → focal-only GAE/PPO → decoder/value checkpoint

初始 Live 与 Frozen view 的动作等价，因为另外 47 个 Live decoder 尚未分叉。两种 view 当前用于验证独立身份、调度、provenance 和未来 curriculum 路由，不能被解释成两种不同 opponent 强度。相同 head 使用写时复制语义，不在 GPU 上重复 48 份相同 tensor。

模型与梯度

组件训练状态参数/职责
Shared 0019 Encoder冻结卡牌、场面、资源、event、exact deck 与 legal option 表示；每次更新前后 SHA 必须一致
Focal action decoder训练pointer key/query、option bias、decoder init、GRU decoder、STOP，共 1,027,202 参数
Focal value head训练LayerNorm + 320→320→1 + Tanh，共 103,681 参数
其他 47 Live + 48 Frozen第一版冻结只提供 opponent 动作；不采集 opponent loss，不参与 backward

每个可变 checkpoint 合计 1,130,883 参数，只包含 Decoder/Value tensor、Foundation/deck hash、policy role/version 和 update。optimizer、scheduler、GradScaler、RNG、rollout、replay 与完整 Foundation 一律不保存。

正式更新

48 Frozen views + 48 Live views = 96 matchup identities
512 official-engine games / PPO update
256 focal-first + 256 focal-second
terminal reward: win +1 / loss -1 / draw 0, gamma = 1
every 5 updates: 48 Frozen decks × both seats = 96 greedy games

rollout/source_policy_update=k 表示对局由 update k 的 behavior policy 采集；该批 PPO 生成 checkpoint/update=k+1。sampled rollout 胜率只作训练诊断，checkpoint 强度以独立 eval/* Frozen greedy 对局为准。一个 focal batch 不能声称为其他 47 套提供了 actor 数据。

证据边界

Frozen 胜率改善只能证明相对当前 48-deck anchor 的局部改进，不能证明全局最优。Live-view rollout、loss、KL 和 reward 不能冒充 checkpoint 强度。真正启用其他 Live deck 的 actor gradient、League 共进化、开放 Encoder 或加入新机制，均必须创建新的不可变版本并重新执行 smoke、Frozen gate 与设计同步。

当前尚未产生正式训练结果；smoke 与 canary 只证明工程和优化合同可运行。
