当前合同

Foundation

严格绑定 0019 Epoch 13，17,756,162 参数，SHA-256 da9b13d6…e5bb；source_id 永远为 0，Encoder 长期冻结。

48 Frozen

evaluation/arena/frozen/ 保存一个 Foundation policy 和 48 个轻量 exact-deck identity。训练期间永不更新，是默认 greedy 回归评测池。

Focal + 47 Live

一次只给一个 focal deck 主要采样与更新预算；其他 decoder 保留资产，并仅从自身真实 actor trajectory 作机会式更新。

Official engine

每局在隔离 worker 中执行未修改 official runtime。CPU 负责状态转移，双方策略动作由父进程集中 GPU 推理。

运行拓扑

isolated official-engine workers (CPU state transition)
    ├── candidate requests → resident batched GPU service → candidate action
    └── Frozen requests  → resident batched GPU service → Foundation action
                             exact 60-card deck routed per session

48 个 Frozen identity 共用一个 0019 Foundation 模型与共享 Encoder；candidate 使用另一常驻 GPU 服务。因此所有策略决策都享受 GPU batching，一次评测只加载两份完整模型，而不是 49 份。官方 engine 仍是唯一状态转移来源。

运行与存储

边界行为
启动磁盘少于 100 GiB free 则拒绝分配 version
运行磁盘少于 80 GiB free 时在完整 update 边界干净停止
Version cap超过 10 GiB 立即失败；不保存 rollout buffer 或 optimizer
Checkpoint每个 deck 保留最新 2 个和每个 gate update 的 snapshot；每个文件原子写入并带 SHA sidecar，版本 cap 前自动清理
训练时限约 20 GPU 小时；到时间后完成当前 update 再结束
人工停止SIGINT/SIGTERM 只设置 stop request；完成当前 update、checkpoint 与指标后在边界退出

Checkpoint 身份

每套 deck 长期维护不可变 foundation、最新训练产物 latest/challenger 和通过 Frozen Arena 验收的 champion。latest 绝不自动覆盖 champion。

证据边界

Frozen 胜率改善只能证明相对当前 48-deck anchor 的局部改进，不能证明全局最优。Live-view rollout、loss、KL 和 reward 不能冒充 checkpoint 强度。历史异构池仍可通过 --pool opponents 显式运行，作为 secondary external-generalization evidence。

sampled rollout 与 96-game diagnostic 始终只是训练诊断；480-game Frozen Arena 才是标准 checkpoint 验收合同。
