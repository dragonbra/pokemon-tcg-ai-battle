缓存与 dirty graph

Card 使用稳定 (kind, serial) entity key 与 placement overlay；无附件 leaf 使用带类型护栏的 equality fast path，附件树仍做完整 consumed-field projection。Event 复用 immutable payload 并动态更新 age/relation；option 每步更新，但 prototype semantic expansion 按 normalized key 复用。绝对 card index 不跨 layout 复用，parent/event/option relations 按当前 layout 重定位；duplicate serial 会 fail closed。

V2 实测了 decoded-observation boundary 的 whole-layer/zone version：语义正确，但 525 decisions 中完整 CardLayer 仅命中 10 次，zone 命中主要来自空或很小的区域，dirty zone 仍需 entity traversal 和第二次 assembly，因此该重复扫描没有接入 online path。最终接入的是标准库 C 实现的 protocol-5 type-exact binary commitment，用一次保类型的低成本 commitment 替代 Python recursive card projection；它不改变 Engine JSON，也不会把 True、1、1.0 混为一谈。

Resource age-split 原型仅独立验证，未接入 V1：median 改善 23.3%，但 p95 回退 36.1%。周期 shadow mode 也是下一阶段要求，V1 不声称已经实现。

Logs 只是 dirty hint；primitive signatures 是护栏。禁止 whole-observation JSON hash 和 recursive whole-layer freeze。duplicate serial、chronology/actor/deck mismatch、未知结构与非法 relation 均 fail closed 到 stateless authority。

基线与准入

35-decision golden fixture SHA-256：0db50f9991849143aba40053f2c5751f2063f76f4f636bb10e0ad0215b0c254e；扩展 fixture 为 10 条完整 actor-local trajectories、525 decisions、双方 seat、7 套 exact deck，SHA-256：87aa39bb7dd8023db0bd05afa954416519bc4abf64552d4a4eff270288d96485。两者均通过完整 record 与 39 tensors exact parity。原始 full baseline：knowledge 0.127 ms、compiler 0.580 ms、collate 0.454 ms、total 1.190 ms；被拒绝的 coarse whole-layer 路径为 1.237 ms，而 full 为 0.593 ms。

最终 paired/interleaved 基准为 7 repetitions × 5,000 chronological decisions（另有 1,000 warmup）：compiler median 0.574 → 0.430 ms（-25.1%），total 1.166 → 1.069 ms（-8.3%），wall throughput 813.9 → 826.7 decisions/s（+1.6%）；compiler p95 0.820 → 0.934 ms（+14.0%）。因此 V1 未通过性能准入。

V2 最终门禁为 7 repetitions × 10,000 chronological decisions（另有 1,000 warmup）：compiler median 0.591 → 0.437 ms（-26.0%），compiler p95 0.950 → 0.910 ms（-4.3%），total 1.219 → 1.069 ms（-12.3%），wall throughput 734.2 → 769.9 decisions/s（+4.9%）。V2 已修复 V1 的 tail regression，但仍未达到 compiler ≤0.25 ms、relative ≥50% 和 end-to-end ≥10% 的准入目标。

准入要求：record 与 39 tensors 精确 parity；shadow/logit/action 0 mismatch；compiler ≤0.25 ms 且至少快 50%；128/128 official-engine、0 error；N16E8 至少 +10%；N16E1 不回退超过 3%。通过前默认使用 stateless full path。

阶段

V2 保留自包含 lineage、golden commitment、525-decision 多轨迹 parity、card/event fragment、option semantic cache 与 fail-closed fallback。由于绝对 median 和端到端门仍未过，online/export 默认继续使用 stateless compiler。下一阶段若要跨过当前上限，必须让 observation producer 提供原生 dirty/version 信息，或直接复用 tensor segment，避免 Python 层再次遍历和 materialization；随后再补 periodic shadow、checkpoint logit/action 与同合同 N16E1/N16E8 official-engine profile。V2 不产生训练 checkpoint 或 W&B run。
