0021 Corrected Persona-Free Universal BC

Status: non-trainable scaffold. Persona conditioning has been removed and feature/target/loss corrections are tested, but corrected materialization and IID/deck-OOD split audits must pass before V1.

Intended Policy

pi(action | actor-relative causal state, exact own 60-card deck,
            causal visible history, unordered legal-option set)

Teacher/team identity is provenance only. Winner-side actions remain the only BC targets.

Data Flow

actor-visible observation + exact own deck + legal options
  -> actor-relative codec
  -> board/entity encoder + causal resource/event memory
  -> unordered option-content encoder
  -> R15 scenario/goal integration
  -> gradual-option pointer decoder
  -> legal action; learned STOP only when optional

The scaffold directly instantiates R15DeterministicGradualOptionPolicy. Source embeddings and source residuals are absent. The corrected model has 17,346,562 parameters after removing the 129 x 320 option-position embedding.

Required Contract

  • No source, persona, team, submission, absolute player identity, or option-list position in Actor input.
  • Global seat, event actors, and public zone rows are Actor-relative; zones are ordered self then opponent.
  • Legal-option permutation equivariance.
  • STOP target for optional_stop, not forced_max.
  • Mean per-decision sequence NLL.
  • Separate Episode-IID and meaningful deck-OOD validation.
  • Atomic, bounded exact epoch-boundary recovery checkpoints and W&B online recording.

Data Boundary

The accepted 0019 winner Episode/player membership is frozen, but its model-ready shards are not trainable 0021 input. Corrected shards require a new schema and commitments. The verified preflight split contains 76,453 train, 8,280 IID-validation, and 4,770 deck-OOD Episodes; the OOD set has 20 exact decks with at least 50 Episodes each.

Release Gates

  6. Smoke validation of checkpoint, TensorBoard, and W&B contracts.

Checkpoint and Resume Contract

0021 V1 is a user-authorized exception to the model-only default. Each completed epoch saves model and AdamW optimizer state, optional scheduler/GradScaler state, trainer counters and history, plus Python, NumPy, Torch CPU, and all Torch CUDA RNG states. Resume is allowed only in the same repository version and stable W&B run after the dataset, feature compiler, model config, and training config hashes match.

The boundary is a fully completed train + IID validation + deck-OOD validation epoch; it does not claim mid-epoch DataLoader recovery. Named criteria retain at most eight full recovery files and publish retained bytes. W&B additionally receives every-100-batch running loss, throughput, gradient norm, learning rate, elapsed time, and GPU memory telemetry.

Formal V1 also enforces at least 43,200 accumulated seconds (12 hours) of complete CUDA epoch work before early stopping may fire. This counter is checkpointed and restored across process interruptions.

Later Research Boundary

Both players' visible states may be used by a separately versioned representation or transition objective. Loser actions must never become BC labels, and V1 contains no unvalidated auxiliary objective.
