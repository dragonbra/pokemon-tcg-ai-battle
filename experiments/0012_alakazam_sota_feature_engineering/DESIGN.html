版本语义

版本输入/结构变化目的
V1_baseline_control保留 0010 option position 与共享 source/target 求和。同代码路径、同 seed 的冻结 control。
V2_no_position_permutation不读取 option position；训练随机置换候选并同步重映射 expert index。消除 simulator 候选排序 shortcut。
V3_role_separated_actionsource 与 target 使用独立线性投影；其余合同同 V2。保留动作方向与角色语义。
V4_action_primitive_context首次增加 option_primitive_cat [B,M,4] 与 action_context_cat [B,4]；发现 permutation 未同步重排 primitive 后中止。保留为无效编码 run，不用于模型比较。
V5_action_primitive_permutation_fix对 option_cat 和所有 option-aligned primitive 使用同一 permutation，从随机初始化重训。有效测试稳定 action primitive/context 语义。
V6_chosen_transition_aux首次 transition run 在首 batch 因 AMP stop-mask dtype overflow 失败。保留为无效运行时 run，不用于模型比较。
V7_chosen_transition_amp_fixstate 与专家所选 action mean 经 32 维 trunk，输出 transition_delta [B,11] 和 turn-change logit；mask 使用 stop 自身 dtype minimum。显式学习所选动作至下一 decision 的可观测效果。
V8_action_history从 V3 独立分支增加 action_history_cat [B,H,6]，H≤16；token 含过去 select type/context、option type、source/target card 与相对位置。让 action Query 读取到达当前状态的本方决策路径。
V9_live_action_count_contract不训练新权重；live inference 保留 simulator 原始 minCount/maxCount，pointer 可超过训练上限 16 继续解码到真实 option count。让 Xerosic 大手牌弃牌等 minCount>16 状态可表达并通过 engine legality。

形状与监督

沿用 0010：global categorical [B,4]、global numeric [B,12]、entity categorical [B,N,7]、entity numeric [B,N,5]、option categorical [B,M,12]、targets [B,T]。V1–V3 不改变冻结 dataset shard；V4–V7 的 primitive/transition shard 保持完全相同的 238,356 decision identity 和 split。

V7 总 loss：L = L_policy_CE + 0.10 L_same_turn_delta_MSE + 0.05 L_turn_BCE。11 维 delta 为双方场面及我方 hand/deck/prize/discard/damage/energy 的归一化变化；只在 next frame 存在且 turn 未变化时监督 delta。early stopping 始终只看 validation exact-action。

长 action audit 对同一 3,104 个 winner-player replay group 找到 238,439 个原始 decision frames；0009/0010 的 238,356 条记录恰好漏掉全部 83 条 action length>16 标签，最大长度 25，其中 Xerosic 79 条、Hand Trimmer 4 条。V9 不改变训练张量或 checkpoint 参数：训练 T≤17（最多 16 个 option 加 STOP），而 live greedy 输出为 list[int]，长度强制满足 observation 的真实 minCount≤|a|≤min(maxCount,M)。长度超过 16 时 GRU 复用已训练权重自回归外推；这是 legality 修复，不声称已学到尾部选择。用户指定的最终重训版将使用 max_action_steps=32、恢复 83 条标签并令 T≤33。

候选列表 permutation 不改变专家多选动作的选择顺序，并必须对 option_cat、option_primitive_cat 等所有 option-aligned tensor 使用同一 permutation。E4/V7 只标注专家选中动作加自动 engine consequence，不产生未选择动作的 counterfactual label，不声称得到了真实 Q 值。

当前 / 下一阶段

V1–V3 已完成训练；V4 因 option-aligned primitive 置换错配被审计为无效并中止；V5 修复后完成训练并以 exact 0.845023 成为当前离线 SOTA。V6 transition 在首 batch暴露 AMP stop-mask dtype overflow，已保留失败身份并增加 autocast 回归测试。V7 完成 21 个 epoch 后按用户要求在 epoch 22 中止；best exact 0.843851，best loss 0.218391，未超过 V5。首轮 V1/V2/V3/V5 official evaluation 暴露 minCount>16 时的 decoder contract 错误；V9 probe 用同一 V1 checkpoint 达到 200/200 finished、0 errors，已作为独立 policy update 固化。V8 暂停且不启动；后续由用户从 V1–V7 指定一个 SOTA 基座，只训练一份完整的长 action 数据合同修复版。
