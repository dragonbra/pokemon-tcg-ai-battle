Input and model flow

Actor-visible board, legal full-action options, exact registered deck, causal ledger, events and opponent knowledge boundary enter the frozen V12 R2 encoder. Four Goal-QKV roles and two scenario layers condition state/options through neutral-1.0 ScaleGates. A declared team persona residual with scale 0.05 is applied after the R2 encoder because several expert policies are present; source ID 0 is zero-neutral. The ordered-action codec, BC objective and online greedy decoder share a 64-step maximum, replacing V12's old 16-step action horizon without adding model parameters. Across 845,405 frozen decisions the observed maxima are action/min/max count 26 and option count 50; 360 decisions exceed 16 and none exceeds 32. A capacity-independent count-valid fallback protects future runtime observations outside this trained envelope.

V2 R15 single-variable comparison

V2 is a project-local adaptation of 0014 R15 and has no runtime import from another numbered project. It preserves the complete R2 state/option evidence paths, source-persona residual, tensor shapes, Goal-QKV roles, legal masks and 64-step output contract. State ScaleGate initialization remains 1.0; only option ScaleGate initialization changes from V1's 1.0 to 0.35. Both variants contain 17,601,282 parameters, so the formal comparison holds the dataset, seed, AdamW configuration, batch sizes, validation cadence and early stopping fixed.

Training

Winning Alakazam Episodes only; whole-Episode grouped splits; full-action BC cross entropy. One train update pass and one complete teacher plus greedy validation pass per epoch. AdamW, LR 3e-4, WD 0.02, batch 256, validation 512, BF16, seed 20260723. Early stopping follows validation loss. The run preserves loss-best, teacher-exact-best, greedy-exact-best and latest checkpoints; exact-action is diagnostic, while controlled official-engine games select the deployment candidate. V1 completed at epoch 17; epoch 12 is its validation-loss best at 0.2552687146 with 81.9283% exact and 100% legal action. The R15 comparison is V2_win_multideck_r15_gradual_option; both use private W&B online logging.

Recovery contract

Formal V1 resumes only inside the same immutable version and stable W&B run after checkpoint SHA, dataset, model, feature, optimizer and hyperparameter checks. The host power loss interrupted epoch 9, so recovery uses the complete epoch-8 checkpoint at global step 23,760 and replays epoch 9 from its beginning. That older checkpoint has no RNG snapshot: weights, AdamW moments and deterministic epoch ordering are preserved, while the dropout stream is new. Post-recovery checkpoints persist Python, NumPy, Torch and CUDA RNG state.

Boundaries

The project is self-contained and does not import another numbered training project. Official card data, rl_environment, evaluation and official engine runtime remain shared. The default target deck lives at train/0016_alakazam_multideck_bc/deck.csv. Controlled deck-comparison exports may provide another exact 60-card deck while keeping checkpoint weights fixed; each candidate manifest records the deployed deck source and hash. Candidate admission and Kaggle submission require explicit user authorization.
