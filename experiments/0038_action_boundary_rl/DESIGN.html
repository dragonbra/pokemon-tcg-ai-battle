DecisionGate

Gate 位于 observation consumption 后、tensor compilation 前。分类为 TERMINAL、LEGAL_EMPTY_PASS、MASK_ERROR、FORCED、STRATEGIC，并记录 chance/information/priority boundary。只有唯一 canonical completion 且不存在 STOP/cancel/decline/pass 才 shortcut；forced 仍消费 knowledge/history/event，但不调用 Transformer、GRU、Value 或服务。

Phantom Dive

DragapultDamageAllocation {
  target_ids: stable (player_index, serial, card_id, initial_bench_slot)
  counters: [x1, ... xn], xi >= 0, sum = 6
}

分配数为 C(n+5,6)=C(n+5,n-1)；n=1..8 时为 1、7、28、84、210、462、924、1716。目标用 stable serial canonicalize；目标顺序不产生 action alias。

log P(complete action)
= log P(root action)
+ log P(allocation | state, Phantom Dive)

Root softmax 完全不因 allocation 数量改变。conditional head 复用同一次 state/cards/root-option embeddings，并以共享 target MLP + permutation-invariant sum pooling 评分。

当前目标合同支持 1≤n≤8，包括零之大空洞扩展 Bench。候选超过 210 时仍在同一次 State Encoder 结果上由 conditional head 批量评分；不得退回六次 Encoder/Value/PPO transition。transaction 漂移必须保留 trace、使样本无效并 fail closed。

混乱状态在 root commit 后、allocation 前揭示硬币结果，属于真实 chance boundary；release 修复必须重新证明此路径，不能用 legacy 多次 Policy/Value callback 冒充 compound transition。

官方协议

MacroPlanner 在 root request 生成完整分配；PendingMacroTransaction 以 battle ID 隔离；OfficialProtocolExecutor 在六个 callback 中消费 observation、校验 actor/context/remain/effect/legal set、按 serial 重新定位，然后仍返回单个 primitive index。任何漂移均 fail closed 并使 rollout 样本无效。Prize 可见特征由同一版本化 public prototype 映射提供，Mega Evolution 只按名称前缀 Mega 判断，避免把 Yanmega ex 误作三奖。

Trajectory 与 PPO

EngineEventTrace 保留所有 primitive event。PolicyTrajectory 只保存真实决策边界，joint old logprob 为 root 与 parameter logprob 之和。内部 callback 不产生 Value 样本，不进入 policy/entropy/KL/clip，也不增加 gamma/lambda。terminal 在 chain 中发生时归入上一个真实 transition 且 next value 为 0。

delta = reward_acc + discount_acc * next_value - value
advantage = delta + discount_acc * lambda_boundary * next_advantage
lambda_boundary = 1 (同一 official turn)；lambda (跨 turn)

模块化目标

V_win 与终局 ±1 不变；V_prize 使用 Query 3 sidecar，own-turn clock 下独立计算并单独标准化 A_prize。Opponent Meta 只读取公开 state/history，true deck ID 只作 label，预测经 detach 与 zero conditioner 进入 Action summary。Tempo 第一版只记录公开 attack opportunity、第二己方回合攻击和 streak，不启用 reward/loss。预设为 BASE、PRIZE、META、PRIZE_META、INTEGRATED。

Rollout 与诊断频率

games/workers/envs/inference/queue/minibatch/accumulation/epochs/optimizer steps 均配置化。accelerated:cuda_resident backend 复用同一 DecisionGate、hierarchical Phantom 与 primitive-select 合同，只保存真实 Policy boundary。macro trajectory 同时保存当时公开的 allocation feature snapshot，以精确重放 joint old-logprob；任何事务漂移均 fail closed 并排除 PPO。V10 的 fixed_optimizer_budget 每 update 运行两个完整 256-slot unit，共 512 局，并保留全部 512 条完整 EpisodeTrajectory；不再额外模拟不会进入梯度的 1,536 局。固定优化预算仍为 32 × 1024。update 结束后显式释放 batch/Episode/collector 高维 tensor，避免与下一批 rollout 重叠。每 update 只写聚合 scalar；Frozen 指标离线聚合；梯度/cosine/margin/calibration 只在 update 0/5/10/之后每 10 次的固定小 batch。

Frozen 2,048

正式评估唯一合同为全局 frozen_0806_seeded_2048_v2：evaluation seed 341512806，8 replicas × 原始 256-slot 环境频率，共 2,048 个唯一 seed、先后手各 1,024；007 schedule SHA-256 为 98b58b...ce9。update 0 与之后每 5 updates 复用相同 slot/opponent 权重/seat/greedy/CUDA/termination 合同。历史均匀 0038_frozen_2048_v1 仅保留旧证据。训练 rollout 使用不同随机 seed，但每个连续 256-game unit 精确复现环境 opponent 频率。
