Model And Cost

Default: 320 dimensions and 8 heads; a four-layer global+card board encoder; one event layer; tokenwise resource memory; a three-family summary MLP; two option cross-attention layers; and an ordered pointer plus STOP. Capacity is 56,352,322 parameters. The complete option memory remains exactly 1 + C + R + E tokens. Every card, resource, and event instance stays actor-visible; only the expensive interaction topology changed.

Categorical columns retain disjoint parameter rows but execute as one packed lookup per family. Numeric scalars retain independent two-layer parameters and field-state embeddings but execute as batched contractions. These fusions do not merge semantic fields.

Shared prototype tables use torch.nn.functional.embedding for identity lookup. The dense trainable tables, lookup values, identities, and parameter sharing are unchanged; only the backward operator is specialized.

Across 512 chronological real decisions, card-family tokens average 55.85 versus 45.11 (+23.8%); 5.87 are resolved Energy units. Median warm feature compile is 0.573 ms/decision versus 0.301 ms for 0025 (1.90x), still below 1 ms.

A coarse production-width batch-32 A/B on 2,098 real V2 decisions, while 0030 RL shared the GPU, measured the accepted hierarchy plus fused AdamW at 150.6 decisions/s versus 128.6 for the packed-field joint-state reference (1.17x). Fused AdamW measured 150.6 versus 134.7 for standard AdamW (1.12x). These runs establish direction, not isolated formal throughput.

Canonical compile workers now serialize their final rows and return only compact audit metadata; decompressed train/validation hashes match the former main-process serializer byte for byte on all 2,098 sample decisions. Canonical shards use manifest-recorded gzip level 3 to reduce one-time build time without changing training records.

Compile Status

Teacher forcing now enters module forward, data-dependent decoder indexing was removed, and a real backend="eager", fullgraph=True regression passes. Model-only saving unwraps compiled modules, so ordinary eager models load clean keys.

Inductor is not ready. Even d32/batch-1 full-prototype compilation created a very large graph and 16 multi-GB compile workers without finishing in the diagnostic window. The sample also had 124 joint bucket signatures across 2,048 decisions. Formal run_bc therefore exposes no compile switch.

Training And Resume

BC performs one train pass and full teacher-forced plus greedy validation per epoch, with fused AdamW on CUDA, prefetch depth 4, and private W&B for formal runs. Teacher loss uses dense cross entropy with padded targets set to ignore_index=-100, retaining the valid-step mean reduction. Canonical gzip JSON rows are decoded with orjson 3.11.5. Every completed epoch is retained as an immutable model-only epoch_XXXX.pt; latest plus three best criteria remain replaceable inference/export aliases. One atomic checkpoint/resume/latest_resume.pt additionally stores model, AdamW, optional scheduler/GradScaler, completed-epoch trainer state, and Python/NumPy/Torch RNG.

Resume requires identical dataset, training config, model contract, and implementation hashes plus agreement with the canonical metrics epoch. The exact boundary is a completed epoch; an interrupted partial epoch is rerun. The active V4 epoch-3 model-only file is approximately 443 MiB, so all-epoch retention grows by approximately 443 MiB per completed epoch in addition to four aliases and the resume slot; automatic rotation and deletion are forbidden. V4 epoch 3 was recovered byte-for-byte as epoch_0003.pt with SHA-256 e1c0a59289185d9a508c49a679ff954a30c54c3cdc7a3602de0834c4af015ed0. Resume state never enters a candidate.
