PPO 与时间轴

checkpoint k-1 → sampled rollout(source_policy_update=k-1) → PPO → checkpoint k → 102-game frozen greedy eval。终局 reward 为 -1/0/+1，γ=1.0，GAE λ=0.95，clip=0.10，4 epochs，decoder LR 1e-5，value LR 1e-4，初始 decoder anchor=0.02，target behavior KL=0.02。只有焦点决策进入 PPO。

Trajectory 不保存原始全特征用于重复编码，只保存 summary、contextual options、mask 和选择上下限。每行先裁剪真实 option 数，CPU 缓存用 fp16，decoder 前恢复 fp32；prototype memory 只在 GPU 上预计算一次。benchmark 会把 actor.encode 替换为 fail-closed 异常，确认 PPO encoder 调用严格为 0。
