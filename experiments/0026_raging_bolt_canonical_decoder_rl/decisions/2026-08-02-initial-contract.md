# 0026 Initial Contract

0026 tests whether the canonical semantic representation learned in 0025 can support
official-engine reinforcement learning for the exact James Cox / James Cox & Henry Chao
Raging Bolt deck.

- Initialize the actor from 0025 V4 `best_greedy_exact`, epoch 14.
- Freeze `prototypes`, `state_encoder`, and `option_encoder` bit-for-bit.
- Train exactly `actor.action_decoder.*` and a newly initialized `value_head.*`.
- Use all 51 Frozen 0019 Foundation exact decks as immutable greedy opponents.
- Use terminal actor-relative reward only: win `+1`, draw `0`, loss `-1`.
- Collect stochastic focal actions and record only focal decisions in PPO trajectories.
- Treat each sampled batch as generated by `source_policy_update=k-1`; never call its
  post-update checkpoint `k` strength evidence.
- Compare checkpoints with a separate 102-game greedy suite: every opponent once in each seat.
- Save model-only checkpoints. Optimizer, RNG, rollout, replay, and engine state are excluded.

This experiment can show whether the frozen semantic memory is usable by a trainable decoder.
It cannot, by itself, prove that the semantic representation is complete or that a sampled
win-rate change generalizes outside the frozen league.
