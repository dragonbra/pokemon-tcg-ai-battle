方差、护栏与诊断

训练 rollout 保持每 update 512 局（256 seed 换手配对）；Frozen Greedy 评测改为 2,048 局：相同 256-slot deck schedule 重复 8 次，每个 slot 使用 8 个独立 engine/Search seed，严格 4 次先手、4 次后手。checkpoint 0 与每 5 updates 使用同一环境 commitment；历史 seeded-512 不与新合同拼接。value_diag/* 按官方 turn、距终局和 focal win/loss/draw 拆分 Value mean、residual 与 GAE/terminal explained variance。

另有 0037 项目级无进展护栏（不是官方规则）：同一 actor 在同一官方 turn 内第 20 次返回相同 selection/action 时立即判该 actor 负，并在报告中单列，不冒充官方终局原因。

Engine CUDA 当前合同

共享路径包含 GPU Semantic0031 compiler、静态 prototype cache、共享 state Encoder/Option block 0、focal/opponent 最后 Option block 分支和 masked lane refill。Option skill/effect 只按当前 action 的显式 ID、role、parent 与 mask 聚合，不根据卡牌 prototype 猜测 relation。Greedy 端不构造无用的 Categorical/log-prob/entropy。TF32 的两次 2,048 局复跑有 1 局普通 outcome 漂移，因此当前合同强制 highest/strict FP32；两次严格复跑都是 1174-874-0，outcome、16 个 repeat-forfeit 索引和 raw terminal state 全部相同，吞吐仍为 21.888–21.893 games/s。PPO focal 端按每局独立的 (policy seed, focal decision, ordered step) 采样；4 局 smoke 共 321 个 focal decisions，严格重放最大误差 2.86e-6，并完成一次 optimizer minibatch。循环护栏按 physical actor 独立保存同一官方回合内的选择计数，另一方行动不会清空计数，第 20 次相同选择由重复方判负。评测在 raw engine turn 100（50 个完整回合）记平局；0037 RL 为对齐历史 CPU 合同在 raw engine turn 99 记平局。该时钟直接读取 OfficialStatePod.turn 的零拷贝 tensor view，不使用归一化 feature。CUDA/official CPU parity 完成前，报告明确标记 CUDA evidence。

正式 512-Episode stochastic rollout 验收共 46,629 个 focal decisions / 95,313 次总推理请求：resident hot loop 45.670 秒，CPU trajectory materialization 7.649 秒，端到端 collector 约 9.60 games/s（hot loop 11.21）。轨迹 staging 2.409 GB，PyTorch 峰值 allocated/reserved 为 4.425/9.460 GB；PPO optimizer 阶段成本另计。
