残差到底保留什么

x1 = x  + SelfAttention(LayerNorm(x), mask)
x2 = x1 + FFN(LayerNorm(x1))

q1 = q  + OptionSelfAttention(LayerNorm(q), option_mask)
q2 = q1 + CrossAttention(LayerNorm(q1), LayerNorm(state_memory), memory_mask)
q3 = q2 + FFN(LayerNorm(q2))

残差保留的是投影后的 typed token，不是原始 JSON，也不是未经缩放的原始数值。因此 feature compiler 是否如实提供数值、类型和 missingness，仍然是正确性的第一道门。
