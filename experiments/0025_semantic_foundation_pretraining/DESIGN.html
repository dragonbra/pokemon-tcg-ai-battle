Forward 伪代码

def forward(observation, legal_options, selected_prefix):
    causal = ledger.consume(observation.visible_logs)
    actor = compile_canonical(
        observation, legal_options, exact_deck, causal, official_prototypes
    )

    cards    = typed_card_instances(actor.cards, card_prototypes)
    ledger   = typed_resources(actor.resources, card_prototypes)
    events   = typed_events(actor.events, card_prototypes)
    state    = state_transformer(global_token + cards + ledger + events)
    summary  = attention_pool(state)

    q = typed_options(actor.options)
    q += gather(state.cards, actor.option_source, actor.option_target)
    q += lookup(card, attack, parented_skill, parented_effect)
    q = option_cross_attention(q, state, layers=3)

    hidden = initialize_decoder(summary)
    hidden = consume_prefix(hidden, q, selected_prefix)
    mask_selected()
    enforce_min_max_count()
    return option_pointer_logits + stop_logit

每个 Transformer block 使用 pre-norm residual：x = x + Attention(LN(x))，再做 x = x + FFN(LN(x))。padding 只在 collation 出现，state 与 option attention 都用 mask 排除。

当前结论：semantic 从第 1 轮 49.28% 持续学到 73.42%，但没有超过任何 legacy control；parameter-matched legacy 仍领先 5.35 个百分点。因此“当前 semantic 表示本身就能提高离线 BC”的强猜想没有得到支持。它不等价于 official-engine 实战更弱，但说明当前 encoder / routing / optimization 尚未把新增语义转化成更好的 exact-action imitation。
