今晚建立了什么

0025 不是给 0019 多塞一个 attackId。它保留原来的场面、精确 deck、账本、事件和动作序列，再把官方 engine 的 Card / Skill / Attack / Effect 原型变成可引用的 typed memory，让每个 option 分别查询它真正需要的证据。

1 card token + play skill + 对应 effects。没有 HP/attack 的位置不是数值 0，而是 N/A。

Forward 伪代码

def forward(raw_decision, selected_prefix):
    legacy = frozen_0019_codec(raw_decision.observation)
    causal = ledger.consume(raw_decision.visible_logs)

    option_facts = bind_options(
        legal_options=raw_decision.legal_options,
        attack_id=True, prototype_refs=True,
        typed_energy_gap=True,
        base_damage_and_target_hp=True,
        explicit_field_states=True,
    )

    board_memory     = board_transformer(legacy.entities)
    prototype_memory = prototype_transformer(
        lookup(card_refs, attack_refs, skill_refs, effect_refs)
    )
    resource_memory  = resource_transformer(exact_deck, causal.ledger)
    event_memory     = event_transformer(causal.events, causal.known_hand)

    q = encode_option(legacy.options, option_facts)
    q = gated_residual(q, attend(q, board_memory))
    q = gated_residual(q, attend(q, prototype_memory))
    q = gated_residual(q, attend(q, resource_memory))
    q = gated_residual(q, attend(q, event_memory))

    hidden = initialize_decoder(global_state, turn_budget)
    hidden = consume_prefix(hidden, q, selected_prefix)
    mask_selected()
    enforce_min_max_count()
    return option_pointer_logits + stop_logit

每个 Transformer block 使用 pre-norm residual：x = x + Attention(LN(x))，再做 x = x + FFN(LN(x))。新 memory 到 option 的通路额外乘以零初始化 gate，保证刚开始不会强行覆盖 option identity。

这条测试直接覆盖我们从 Crispin 错误中发现的问题：能量不能只作为“附了一个 energy”的计数。对应 attack 的类型需求现在是 option 可直接读取的确定性事实。

尚不能误称为 resolved damage：V1 已经保留完整 Effect/Target/Condition tokens，但直接数值目前只计算 base damage 和保守 typed gap。Special Energy 卡文、弱点/抵抗、工具加血、保护效果、完整 KO/prize delta 仍需下一版 deterministic resolver；未知字段不会伪装成 0。
