Boundary

One deck-specific Alakazam-Dudunsparce policy, trained from complete unique-winning Yushin Ito trajectories dated 2026-07-18 through 2026-07-25. Features are limited to the actor's current observation, actor-visible logs, own registered deck, prior own actions, and causal player-local knowledge. Future frames, outcomes, rewards, hidden opponent construction, and omniscient state are prohibited.

The frozen protocol SHA-256 is da6482cf2d4cdc8d9e56fd4c03431e60dbf63b8327720c83185e907a039d44d3. Formal V1_m0_causal_contract is preserved as failed before epoch 1; it will not be resumed or overwritten.

Shared Compiler

compile_features(raw, registered_deck, knowledge, registry) and tensorize_compiled(...) are the only feature path for chronological offline preparation and official-engine runtime. Offline state is reconstructed per episode-player before shuffle. Runtime resets the same causal state per game.

dataset_reference_v3, model-ready feature manifests, checkpoints, candidate packages, and evaluation manifests bind the typed schema, transitive compiler v2 SHA-256, ontology registry, protocol, source, split, record schema, and action contract. The raw dataset is the provenance layer. The model-ready layer compiles each episode-player once using bounded ordered workers and stores compact hash-committed tensor shards; training only shuffles, permutes, prefetches, and transfers tensors.

A verified complete deck view initializes exact deck and inferred Prize counters. Actor-visible Draw and MoveCard logs update them across later decisions; Shuffle removes order but retains membership. Attached cards, pre-evolutions, Stadium, and the resolving context card participate in serial-deduplicated conservation. Ambiguous transitions degrade the affected hidden zone to unknown.

Goal And Action Decisions

M3 and M4 share one Goal-QKV module. The four latent roles are setup/board development, attack/Prize progress, resource access/recovery, and tempo/survival. Q is the raw state token before entity contextualization. A raw-state-plus-board-summary Q is reserved for an explicit future M3b/M4b ablation. There is no diversity regularizer in M0-M5.

Training permutes every legal option occurrence and synchronously reorders categorical, numeric, semantic, mask, and ordered-target tensors. STOP is masked before minCount; reaching maxCount forces termination with zero STOP probability/entropy contribution. Teacher, greedy, rollout, and future PPO reevaluation share one probability implementation. Full-action greedy evaluation is batched. Formal runs create W&B at startup and report train, train-eval, and validation-eval progress with iterations/s, decisions/s, completion, elapsed time, and ETA.

Value And Evidence

M0-M4 have no active value objective. M5's scalar only establishes a finite action-before, player-relative interface and is not optimized or interpreted during BC. Reward, target, discount, bootstrap, terminal/truncation masks, calibration, and PPO losses require a later synchronized design update backed by official-engine rollouts.

Offline loss, exact action, legality, and permutation audits establish data and imitation health only. Policy strength requires a frozen candidate and official-engine arena report. Promotion into the opponent pool requires explicit user confirmation.

Current Stage

The raw dataset contains 145,961 train and 16,167 validation decisions from 2,110 eligible complete episode-player groups. V1 wrote no complete epoch metric or checkpoint because raw JSON and causal compilation were repeated in every hot-path pass. It is preserved with failure class input_pipeline_throughput_defect.

V2 completed two full epochs but then failed because the mutable criteria/latest.json pointer incorrectly used exclusive-create semantics. Its canonical metrics, W&B run, and two immutable checkpoints remain failure evidence. Selection pointers now use fsynced atomic replacement with a two-epoch regression test. Formal V3 will restart M0 from scratch on the same dataset and optimization contract. M1-M5 are paused.
