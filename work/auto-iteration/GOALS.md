# AutoIteration 长期目标

## North Star

AutoIteration 的长期结果目标是：**在声明清楚评测协议的前提下，让策略胜率逐步接近
90%**。

90% 是长期目标和方向，不是某一轮必须完成的 promotion 阈值，也不是达到一次就停止
迭代的条件。单批次达到 90% 不能证明策略已经稳定；达到目标后仍需继续检查不同先后手、
对手干扰、资源耗尽和长期泛化能力。

## 目标层级

### G0：正确和可运行

- 遵守官方规则和卡牌文本；
- 只选择合法动作；
- 没有崩溃、跨局状态污染和打包契约回归；
- 评测器能正确识别事件和错误。

G0 是前置条件，不能用胜率抵消。

### G1：胜率接近 90%

胜率是最高层结果目标。每次结果都应至少区分总体、先手和后手，保留样本量、胜负平
和异常终局，避免把一个总比例当成完整结论。

### G2：建立可持续的策略能力

过程指标用于观察策略是否具备实现 G1 所需的能力，例如稳定的早期进攻、被击倒后的
连续攻击、资源回收和终局闭环。G2 指标可以在某轮胜率没有明显变化时证明策略正在
沿正确方向移动，但必须说明它和 G1 的机制联系。

### G3：在复杂环境中保持能力

策略不能只在单一对手或单一局面中有效。长期应观察先后手、不同对手造成的干扰、
资源边界和真实官方对局结果。具体观察什么由当前 metric profile 决定。

## 目标如何驱动每轮迭代

每轮记录必须回答：

1. 本轮服务 G0、G1、G2 还是 G3；
2. 当前缺口如何阻碍长期胜率目标；
3. 关注指标为什么是目标的有效观测窗口；
4. 如果当前路径不成立，替代路径是什么；
5. 本轮结果支持继续、暂停还是放弃这条路径。

指标 profile 可以更换，长期目标不会因为某个 profile 表现不好而被偷偷替换。若要
改变 90% 目标或目标层级，必须单独记录目标决策，而不能在 iteration 结果中隐式修改。
