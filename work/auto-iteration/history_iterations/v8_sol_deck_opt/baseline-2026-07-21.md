## Baseline 归因重点

本轮不把胜率的随机变化直接归因到单个规则。策略层面优先验证：

1. `Dunsparce bridge=0` 是否来自没有把 Dudunsparce 当作换位资源；
2. Post-KO 的 `recoverable_discard_miss=130` 是否对应恢复目标选择不足；
3. attack quality 的未拿奖赏攻击是否来自攻击前没有耗尽合法进化、Ability、检索和接力资源；
4. Enhanced Hammer、Nighttime Mine、Fezandipiti 和 Sacred Ash 的局部动作是否与 deck notes 一致。

完整证据位于同一 run 目录下的 `manifest.json`、`summary.json`、`metrics.json`、`games.jsonl`、
`cases.jsonl` 和 `report.html`。
