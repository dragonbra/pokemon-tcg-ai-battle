01 / ENTRY AND BRANCHING

从 observation 到一个合法选择

入口先决定当前是在“主行动”还是“效果选择”；两条路径都只返回模拟器提供的合法 index。

否则：如果 select.type == 0 且 context == 0，进入主行动评分；任何其他 select 进入效果选择。
主行动排序器

不是 if/else 单链

策略会先为所有合法 option 生成 (priority, tie, index)，再取排序第一项。条件 gate 会改变一个动作的分数。

主行动的实际循环

每次主行动 observation 都重复这个排序过程。

读局面 gate→ 列出合法 option→ score tuple→ 取最低分

效果选择的实际循环

选完一个目标后推进 effect serial，下一步重新判断 context。

识别 context→ 选目标/卡牌→ _advance_effect→ 返回合法 index
02 / DECISION GATES

优先级背后的五个 gate

这些 gate 不一定直接返回动作，但会改变 score，决定 setup 是否让位于攻击。

① Setup gate · 先补攻击线

首回合不进化；Poké Pad 优先拿 Dunsparce / Abra。Poffin 在 attack_line_count < 3 或 ready_attack_line_count < 2 时优先 Abra，达到条件后才转 Dunsparce。

② Attack gate · 先问能不能拿 Prize

当前合法击倒为 score 0；有直接 Alakazam 路线时，保留 Active Abra 的 Rare Candy 路线，Bench Abra 才自然进化成 Kadabra。Active Kadabra + Psychic + Alakazam 则自然进化直攻。

③ Draw / deck safety gate · 抽牌不是无条件好事

_draw_is_blocked() 只在抽牌会直接创造击倒时放行例外；否则手牌 > 20、牌库 ≤ 10 或已经能击倒都会限制抽牌。当前 auto_iter 对 Dudunsparce 只在牌库 ≤ 1 时额外保护，是明确风险点。

④ Energy gate · 一条线一张能量

Telepath Energy 优先未充能 Abra 线；手里有 Abra 且场上没有攻击线时先放 Abra。已带 Psychic 的 Abra 线不重复贴；Enriching Energy 只在 Active Alakazam 已能攻、没有未充能攻击线且有 Dudunsparce 时换抽牌。

⑤ Prize / interaction gate · 只为具体收益打扰

Alakazam 对手带 Mist Energy 时估伤为 0，优先 Enhanced Hammer。Boss 只在能击倒、提高 Prize 价值或满足 Iono 定向条件时用；Fezandipiti ex 需要上一回合被击倒且不会暴露不必要的两奖目标。

注意：分数与状态绑定。例如 Hammer 在 Mist 阻断时可以是 0，但没有特殊能量时会退到更低优先级；页面展示的是规则实际使用的典型结果。

v5_auto_iter 的决策器

主行动与效果选择共享同一个确定性入口。
  • 左侧节点会显示对应的真实函数和策略条件。
  • 流程中的“优先”指排序分数更低，而不是执行时强制跳过所有其他合法 option。
  • 如果分数相同，使用 option index 保持稳定。
