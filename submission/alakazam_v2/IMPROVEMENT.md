# Alakazam V2 改进记录

V2 的核心目标是把当前策略从“能做出合法动作”提升为“围绕抢先出手、持续攻击和奖赏交换做回合规划”。当前 `deck.csv` 以 V1 卡组为起点；明确的卡组调整见第 5 节。

## 1. 能量管理

### 1.1 减少不必要的撤退

当前 agent 不应频繁通过撤退丢弃能量。能量是本套卡组的稀缺资源，撤退前必须判断它是否真的能改变局面。

具体规则：

- 如果前场已经是胡地系列宝可梦，且本回合可以进化成胡地并攻击，不应撤退；
- 如果前场宝可梦仍然可以承担本回合的进攻计划，不应为了换位随意撤退；
- 只有在无法攻击、必须处理危险对手、或撤退能明确改善奖赏交换时，才考虑支付撤退能量；
- 需要记录每次撤退消耗的能量，以及撤退后是否带来实际收益，作为后续回归指标。

### 1.2 限制胡地的能量数量

这里的“狐狸”是笔误，实际指胡地（Alakazam，Card ID `743`）。胡地的招式只需要一张超能量，不能给同一只胡地贴第二张超能量。

V2 应将“Alakazam 最多一张攻击能量”写成明确的卡牌级规则，而不是依赖模糊的宝可梦名称判断。

### 1.3 前期优先使用特殊超能量

前期同时拥有特殊超能量和普通超能量时，应优先贴特殊超能量。这样可以保留普通超能量，并让备战区尽可能多放 Abra，提升后续进化和持续攻击的机会。

V2 的能量选择顺序应至少区分：

1. 前期 setup 阶段：特殊超能量优先；
2. 胡地准备攻击时：保证攻击手获得一张可用的超能量；
3. 普通超能量：在特殊超能量已经有更高价值用途，或攻击计划需要时再使用。

### 1.4 Ace Spec 能量优先给土龙弟弟

当获得 Ace Spec 能量（当前卡组中的 `Enriching Energy`）时，应优先考虑贴在土龙弟弟身上：

1. 土龙弟弟利用能量完成抽牌或过牌；
2. 进化为土龙弟弟后，利用特性将它和身上的能量一起洗回牌库；
3. 后续再次抽到时继续作为可循环的过牌资源。

这张能量不应被普通的前场贴能或无收益撤退消耗掉。

## 2. 收服者（Boss's Orders）的使用纪律

当前 agent 似乎会比较随意地使用 Boss's Orders。V2 只有在改变局面时才应使用这张支援者，不能因为选项可用就主动使用。

使用前按以下顺序评估：

1. 是否能立即解决关键宝可梦，尤其是阻碍我方进攻或会带来高风险的目标；
2. 是否能通过换出目标，在本回合拿到奖赏卡；
3. 如果两者都不满足，则保留 Boss's Orders，不使用。

在攻击目标选择中，优先拿到当前可兑现的奖赏；只有在无法立即拿奖赏时，才考虑更高奖赏价值或更重要的关键宝可梦。后续实现应记录每次 Boss's Orders 使用前后的目标、预期收益和实际结果。

## 3. 神奇糖果与胡地的即时攻击

神奇糖果在这套卡组中的重点用途，是让前场 Abra 跳过勇基拉（Kadabra），直接进化成胡地并在本回合攻击。

因此，当手上有神奇糖果，或可以稳定找到神奇糖果，并且有可用的胡地时：

- 优先判断能否让前场宝可梦本回合完成胡地进化并攻击；
- 如果可以攻击，不应为了先完成 Kadabra 进化而放弃本回合攻击；
- Kadabra 进化只有在当前无法通过神奇糖果攻击，或其抽牌/后续资源价值明显高于立即攻击时，才应优先考虑。

这是 V2 的核心决策：一次本可以完成的攻击，通常比一个本回合不能攻击的中间进化更有价值。

## 4. 回合目标与整体节奏

这套卡组的定位是抢先建立节奏：第一回合尽可能铺场，第二回合开始用胡地攻击，之后尽量保证每回合都能攻击。

### 4.1 第一回合：铺场优先

当有特殊超能量等铺场能力时，应尽可能在第一回合放出更多宝可梦，尤其是 Abra，为第二回合的进化和后续持续攻击准备足够的候选目标。

第一回合的主要目标是：

- 建立前场和备战区；
- 增加 Abra 的数量；
- 保留能量和进化资源；
- 避免没有收益的撤退、过度贴能或提前使用 Boss's Orders。

### 4.2 第二回合：先确保攻击，再补手牌

如果手上有神奇糖果，或可以找到神奇糖果和胡地，那么第二回合应优先完成胡地并发起攻击。

行动顺序应是：

1. 确认本回合的攻击手和攻击目标；
2. 完成必要的找牌、进化和贴能；
3. 确保攻击合法并尽可能拿到奖赏；
4. 在攻击已经确定后，再考虑抽牌、扩大手牌或为下一回合做资源整理。

### 4.3 后续回合：持续攻击优先

后续每回合先判断“本回合能否攻击、攻击能否拿奖赏”，再决定是否使用抽牌能力、支援者或其他资源。扩大手牌和寻找更高价值目标都不能无理由地取代一次确定的攻击机会。

## 5. 核心宝可梦与卡组调整

当前观察认为，这套卡组的核心宝可梦主要是胡地和土龙弟弟：

- 胡地负责持续攻击和奖赏交换；
- 土龙弟弟负责过牌，并配合能量循环；
- 谢米没有必要时不应主动放入备战区；
- 可达鸭在当前计划中的重要性较低。

V2 的第一项明确卡组调整：

| 调整 | 数量变化 | 原因 |
|---|---:|---|
| 可达鸭（Card ID 858） | -1 | 当前策略价值较低，减少无关起手目标 |
| 胡地（Card ID 743） | +1 | 增加核心攻击手，提升持续攻击和进化成功率 |

后续如果发现谢米仍然经常被动上场或占用资源，再单独评估其数量和备战区优先级。
