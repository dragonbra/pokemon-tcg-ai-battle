# Strategy Adapter V2 Pre-Implementation Architecture Audit

Date: 2026-08-11
Scope: Strategy Adapter / Value-Policy interaction only
Audited formal configuration: `0040_dragapult_0809_action_boundary_rl`, preset `PRIZE`

## Executive findings

1. The target background is not the current runtime architecture. The deployed critic has eight
   latent queries. Query 0 feeds Value, query 1 feeds the pretrained 15-class archetype head, and
   query 2 feeds final-Prize-difference. There is no single `h_V` currently shared by Value and Meta.
2. Formal 0040 PPO does not enable Opponent Meta. The pretrained 15-class head is loaded but frozen
   and never called. The separate dormant integrated Meta implementation is a fresh 23-class head
   over `state.summary`, not the pretrained 15-class head.
3. Policy and Value are not clean branches after a frozen shared encoder. Both consume the
   trainable last-option Q/V LoRA: policy loss updates it, and Value loss also updates it because
   Value memory includes post-LoRA option tokens. Stop-gradient on future Value outputs will not
   remove this upstream shared-parameter coupling.
4. There is no unique current `h_pi`. Root logits depend on a 320-wide autoregressive decoder
   hidden, every 320-wide option token, and option-specific bias. A Strategy Adapter insertion point
   is therefore a design decision, not a mechanical wrapper around an existing `PolicyHead(h_pi)`.
5. No hidden opponent deck, label, team, or source identity was found in actor tensors. The broad
   early-turn Meta accuracy of 95.0% initially looked suspicious, but the stricter raw-turn-0 probe
   is only 35.34%, essentially the 34.95% majority baseline. Accuracy rises after public setup/play
   reveals archetype cards.
6. The paired V9 Value signal is useful but not fully calibrated on the available post-hoc local
   validation: weighted AUROC 0.8409, explained variance 0.3437, Pearson 0.5889, Brier 0.1641 and
   ECE-10 0.0309. Exact deck 007 is weaker than other Dragapult builds in this split.
7. The proposed normally initialized residual MLP with scalar `g=0` starts correctly: first
   backward gives nonzero gate gradient and zero MLP gradient; after one gate step, the MLP receives
   nonzero gradient. Zero-initializing the residual output as well would create the warned-about
   dead start and must remain forbidden.

## A. Current Architecture

### Real forward graph

```text
public observation + registered own exact 60-card deck
                    |
                    v
       prototype encoder (frozen, shared Parameter objects)
                    |
                    +------------------------------+
                    |                              |
                    v                              v
       StateEncoder (frozen)         OptionEncoder base (frozen)
       state.tokens [B,S,320]        + last block Q/V LoRA (trainable)
       state.summary [B,320]         option.tokens [B,O,320]
                    |                              |
                    |               +--------------+
                    |               |
                    v               v
       ActionDecoder.initialize     concat(state.tokens, option.tokens)
       hidden_0 [B,320]              Value memory [B,S+O,320]
                    |                              |
       selected option -> GRU                      v
       hidden_t [B,320]              8 learned queries + 2 cross/self blocks
                    |                 + final affine LayerNorm
                    |                 queries [B,8,320]
                    |                  |       |       |
                    |                  |       |       +-> q2 -> 13-class diff
                    |                  |       +-> q1 -> pretrained 15-class Meta
                    |                  +-> q0 -> Value MLP -> sigmoid -> V in [-1,1]
                    v
 query(hidden_t) dot key(option.tokens) + option_bias(option.tokens)
                    + stop(hidden_t)
                    |
                    v
             root logits [B,O+1]
```

### Code mapping

| Concept | Actual implementation | Finding |
|---|---|---|
| `h_encoder` | `EncodedState.tokens`, `EncodedState.summary`, plus encoded options | It is not one tensor. `state.summary` is `[B,320]`; full state memory is `[B,S,320]`. |
| shared encoder | `OfficialPrototypeEncoder`, `StateEncoder`, frozen base of `OptionEncoder` | Prototype parameters are registered through three aliases but are the same objects. |
| `ValueTrunk` | `LatentQueryValueHead.queries`, `.blocks`, `.final_norm` | Trainable in PPO; input includes post-LoRA options. |
| `h_V` | Closest match is `queries[:,0]` after `.final_norm` | `[B,320]`; only the Value query. Meta does not read it. |
| pretrained Meta latent | `queries[:,1]` | `[B,320]`; feeds `heads.archetype`, but is unused in formal 0040. |
| `ValueHead` | `value_head.heads.value` | Affine LayerNorm -> Linear -> GELU -> Linear; scalar logit then `2*sigmoid-1`. |
| current formal Meta | none | `PRIZE` has `enable_opponent_meta=False`. |
| dormant integrated Meta | `OpponentMetaHead(state.summary)` | Fresh 23-class head, separate from V9's pretrained 15-class head. |
| `PolicyTrunk` | `OptionEncoder` plus `ActionDecoder.initial`/`GRUCell` | The former is per-option; the latter is autoregressive per selection step. |
| closest `h_pi` | `DecoderState.hidden` | Fixed `[B,320]`, but not sufficient alone to determine logits. |
| `PolicyHead` | `query`, `key`, `option_bias`, `stop` inside `ActionDecoder` | Logits require both decoder hidden and option tokens. |

The semantic policy implementation is in `semantic_policy/model/{policy,state_encoder,
option_encoder,action_decoder}.py`. The RL assembly and Value path are in
`policy/actor_critic.py:115-211` and `policy/value_network.py:29-102`.

### Freeze and update boundary

- `SemanticActorCritic.freeze_representation()` first freezes the entire actor and Value head.
- It re-enables the original `actor.action_decoder`, Value queries/blocks/final norm/Value head,
  allocation head and enabled auxiliaries.
- Formal 0040 then installs last Option block self/cross-attention Q/V LoRA. LoRA A is Kaiming,
  LoRA B is zero. The optional Option final LayerNorm tuning is disabled in `PRIZE`.
- PrototypeEncoder and StateEncoder are entirely frozen. The OptionEncoder has 10,240 trainable
  LoRA parameters despite the frozen base.

## E. Value / Meta Baseline

### Training semantics and runtime use

Pretraining 0036 freezes the paired semantic encoder and executes it under `torch.no_grad()`.
The supported objective is episode-weighted Value BCE plus weighted archetype CE and final-difference
CE. The 15-class target is 14 priority-ordered trigger-card axes plus `other`; labels, exact opponent
deck hash and team/source metadata are training/audit-only. The V9 checkpoint metadata does not
retain its exact auxiliary loss weights, so exact V9 training-objective reconstruction is not
possible from this repo alone.

In current 0040 PPO:

- `V = 2*sigmoid(logit)-1`, so its range is `[-1,1]`;
- terminal result is +/-1, `gamma=1`, GAE lambda defaults to 0.95 on turn boundaries;
- PPO trains Value with weighted squared error to the GAE return, coefficient 0.5;
- Value supplies rollout `old_value`, GAE and PPO critic evaluation;
- Value, Meta logits and Meta latent are not inputs to the formal policy;
- pretrained Meta and final-difference heads are frozen and unused;
- on-policy Value MSE can change calibration away from the pretrained BCE calibration.

### Input leakage audit

No prohibited input was found:

- opponent hand/prize identities are required to be opaque or projection fails;
- opponent full registration deck is used to create the training label/audit hash, not actor tensors;
- `CausalKnowledge` initializes only from the acting player's registered exact deck;
- resource tokens encode the player's own exact deck composition and causal ledger;
- opponent card tokens come from public/remembered Active, Bench, discard, played card or logs;
- dataset `labels` and `audit` fields are excluded by the collator;
- `DecisionBatch` rejects extra fields such as `source_id`;
- existing hidden-zone counterfactual tests produce bit-identical features/logits.

Residual risk: the first-decision counterfactual and trigger-visible split should become permanent
regressions for any future Meta-conditioned policy. Aggregate turn buckets alone are insufficient.

## F. Strategy Adapter Integration Risks

| Item | Rating | Audit conclusion |
|---|---|---|
| Value Adapter insertion point | **SAFE** | Use post-`final_norm` query 0, immediately before `heads.value`. This preserves the pretrained scalar head. Do not call it the Meta representation. |
| Policy Adapter insertion point | **BLOCKER** | There is no single sufficient `h_pi`. Decide whether to adapt decoder hidden at every autoregressive step, option tokens, or both. Adapting only `state.summary` does not implement `PolicyHead(h_pi_adapted)`. |
| `h_V` detach | **SAFE** | Detach `queries[:,0]` after Value final norm. This blocks direct policy gradients into Value trunk. It does not remove the existing shared Option LoRA coupling. |
| `V` detach | **SAFE** | Detach the final bounded `[B]` Value after any Value Adapter. Record whether policy context uses pre- or post-Value-adapter V; the proposed semantics imply post-adapter V. |
| Meta detach | **NEEDS CARE** | Preserve V9 knowledge by using `heads.archetype(queries[:,1])`, not query 0 and not the dormant 23-class head. Formal 0040 currently never calls it. |
| Meta reads pre-Value-adapter latent | **SAFE** | Query 1 is already separate from query 0. A Value Adapter on query 0 naturally leaves Meta pre-adapter. |
| LayerNorm ownership | **NEEDS CARE** | Every current LayerNorm is affine by default. Reusing trainable Value norms after `detach()` still lets policy loss update their weight/bias. Give Strategy Adapter its own affine LN, or use `F.layer_norm`/non-affine LN. Independent adapter-owned affine LN is recommended. |
| `h_pi` normalization | **NEEDS CARE** | `state.summary` and option output are already normalized; decoder hidden is tanh output with no LN. Add a Strategy-Adapter-owned LN at the selected hidden boundary; do not reuse State/Option norms. |
| own-deck embeddings | **NEEDS CARE** | No discrete own-deck embedding exists. Create two distinct tables and verify no shared Parameter IDs. Vocabulary keys must be stable exact-deck hashes/IDs; binding only to the 15 Meta classes is insufficient for the repo's exact-deck-conditioning rule. |
| shared upstream Option LoRA | **BLOCKER** | Value and policy losses both update it. Decide explicitly whether V2 preserves this legacy coupling or gives Value a pre-LoRA/frozen option memory. Zero-gated adapters do not solve it. |
| checkpoint compatibility | **BLOCKER** | Current 0040 save selection omits unknown adapter prefixes; strict load requires exact inventory; policy materialization understands only current actor deltas. A new schema/manifest and strict legacy initialization path are required. |
| zero-gated residual initialization | **SAFE** | Isolated two-step regression passed. Keep normal residual initialization and scalar gate exactly zero. |
| zero-init legacy equivalence | **SAFE with test** | Multiplication by finite residual and exact zero gate preserves the input bitwise in a fixed dtype/device. The complete new loader/forward still needs a real-checkpoint regression. |

### LayerNorm recommendation

Use Strategy-Adapter-owned affine LayerNorms. This gives the policy branch learnable normalization
without sharing Parameters with Value. A non-affine LayerNorm is also gradient-safe but removes a
useful local scale/shift degree of freedom. For Value Adapter, use its own Value-side LN. Assert that
the two adapter LNs and two deck embeddings have disjoint Parameter identities.

### Zero-init equivalence specification

Canonical regression:

1. Load the same strict actor and paired V9 checkpoint into legacy and V2 models.
2. Seed CPU adapter initialization, set eval/inference mode, use one fixed compiled fixture and
   verify all residual outputs are finite.
3. Set `g_V=g_pi=0`; do not zero the residual MLP output layers.
4. On CPU float32 require `torch.testing.assert_close(..., rtol=0, atol=0)` for full root logits,
   bounded Value and 15-class Meta logits, plus identical action/mask tensors.
5. Run a second CUDA float32 parity. Prefer exact equality if kernels and call graph are unchanged;
   otherwise use a documented `rtol=1e-6, atol=1e-7` only after showing the legacy-vs-legacy CUDA
   repeatability floor. Mixed precision should use dtype-specific tolerance and is not the canonical
   identity test.
6. Eval mode is mandatory because actor dropout is 0.10. Value-head dropout is 0.0. LayerNorm has
   no running statistics, but affine weights and dtype still affect comparison.
7. RNG should not affect outputs at zero gate, but fix torch/CUDA seeds and deterministic settings
   so failures are attributable. Check for NaN/Inf before multiplying by zero because `0*Inf` is NaN.

Loader behavior:

- A legacy base/V9 pair may omit new V2 parameters only in one explicit legacy-initialization path;
  initialize those modules and assert both gates are zero.
- A V2 model-only checkpoint must require every adapter, gate, adapter LN, deck vocabulary/version
  and both independent deck embedding tensors. Missing/unexpected V2 tensors are fatal.
- Never use broad `strict=False`. Persist adapter schema and exact-deck vocabulary hash in metadata.

## G. Own Deck Identity Audit

1. Focal deck identity exists outside tensors as `FOCAL_DECK_ID=dragapult_ex_07bedfffbfad` and exact
   SHA-256 `07bedf...725`. The wrapper validates a positive exact 60-card list and manifest hash.
2. Actor tensors do not contain a scalar deck/archetype/decoder ID. They contain an exact own-deck
   resource ledger: per-card identity, initial count, visible counts and causal deck/prize bounds.
3. There is no current deck embedding.
4. The policy decoder is one shared checkpoint module, not a per-deck decoder table. Formal 0040
   trains it on fixed deck 007, but the pretrained 0809 policy is exact-deck-conditioned through
   observation/resource features.
5. Value already knows own deck through the shared state/resource memory and options; an explicit
   `E_V` would add a direct identity channel rather than introduce the first conditioning.
6. No deck-specific parameter is stored separately. Actor weights live in the base checkpoint;
   the exact 60-card deck lives in package/manifest assets; RL overlays save shared decoder/LoRA/
   Value tensors.
7. The 15-class opponent label contract and future own-deck vocabulary must remain separate types,
   assets and hashes. Reusing integer values is acceptable only as data coincidence; equating their
   semantic types or embedding tables is not.

The natural interface is a stable exact-deck vocabulary resolved from the registered deck hash at
compile/runtime preflight, carried as an explicit audited model input. `E_V` and `E_pi` should be
separately constructed modules with separate optimizer groups and a regression asserting disjoint
Parameter objects. A coarse archetype may be an additional feature but cannot replace exact-deck
conditioning when multiple exact decks share one archetype.

## H. Recommended Implementation Plan (Do Not Execute Yet)

Because this changes model inputs, effective policy identity, action flow and checkpoint schema, it
should be a new self-contained project, proposed as `0041_strategy_adapter_v2_rl`, not an in-place
mutation of 0040.

### Step 1: Freeze V2 contracts in tests

- Copy the required stable 0040 implementation into `train/0041_strategy_adapter_v2_rl/` according
  to the numbered-project isolation rule.
- Create `experiments/0041_strategy_adapter_v2_rl/DESIGN.md` and `DESIGN.html` with exact tensor
  shapes, query semantics, deck vocabulary and gradient boundary.
- Add tests that first capture current 0040 logits/Value/Meta from fixed real fixtures.
- Add a failing Parameter-identity test requiring `E_V`, `E_pi`, their LNs and optimizer groups to
  be disjoint.

### Step 2: Define exact own-deck vocabulary

- Add an immutable asset mapping exact-deck SHA-256 to a stable own-deck index; do not import or
  alias the opponent Meta taxonomy.
- Extend the 0041 batch/compiler contract with `own_deck_index`, resolved from the already validated
  exact registered deck.
- Reject unknown/mismatched exact decks before forward; record vocabulary hash in checkpoint metadata.

### Step 3: Expose typed Value representations

- In 0041 `policy/value_network.py`, return a typed structure containing all queries,
  `value_latent=query0`, `meta_latent=query1`, pre-adapter Meta logits, adapted Value logit and bounded V.
- Keep the existing V9 15-class head on query 1, frozen initially, and document any later decision
  to train it as a separate experiment variable.
- Add `ValueResidualAdapter` on query 0 only with its own LN, `E_V` and normal MLP initialization.

### Step 4: Resolve the shared Option-LoRA decision

- Before policy adapter implementation, choose and test one explicit contract:
