02 · Full Path

Engine 是物理世界，BC 是人类先验，RL 是价值优化

三者不是互相替代。Engine 提供“会发生什么”，BC 提供“高手通常怎样开始”，RL 提供“在目标环境中怎样更能赢”。

04 · Freeze / Train

阶段不是简单地“越训越多”，而是逐层释放可塑性

点击阶段查看目标和边界。Foundation 永远保留不可变原件；新策略先使用小型 heads/adapters，只有出现可测平台期才开放更深层。

学习“会发生什么”

合法探索产生 (s, a, events, s')。状态 delta、事件、latent forward/inverse 与 masked observation 训练 Card/State/Action Encoders，不提供动作好坏标签。

训练 Encoders新增 Dynamics HeadPolicy 不形成偏好

采集合同

非法动作不参与探索；随机性预测分布；隐藏信息 mask；构筑可以不强，但必须让目标机制可达。

Ldyn = λΔLΔ + λeLevent + λzLlatent + λiLinverse + λmLmasked

学习“高手通常怎样做”

胜者 ordered full-action 通过 teacher forcing 训练共享表示和 pointer policy。Exact deck/source conditioning 分离冲突标签。

训练 Shared Representation训练 Pointer Decoder不声称真实强度

509 sources、367 exact decks；Epoch 13 conditioned greedy exact 81.2871%，neutral exact 74.8431%。

学习“当前局面最后能否赢”

先冻结 actor，只训练新 value head。它把完整 Episode 的终局回报映射到每个 actor-visible state，为 GAE/PPO 提供 critic 起点。

边界

Value calibration 降低预测误差，不自动增强 policy；不能把 in-sample explained variance 当作策略胜率。

学习“这套构筑怎样更能赢”

从 Foundation 分支。先训练 deck adapter、option/pointer head 与 value；只有平台期后才以更低 LR 开放最后 scenario 或 semantic 层。

05 · Engine Physics

没有人类 JSON，也能先学习卡牌世界如何运转

这一阶段不是随机模仿自己，而是使用真实 transition 做自监督表示学习。错误时机打出的卡仍能提供正确效果；策略价值由后续 BC/RL 决定。

采集

st, ordered action, resolved events, st+1

使用覆盖率导向合法探索。实验构筑不必强，但要保证目标卡与依赖机制可达。

表示

Card Encoder + State Encoder + Action Encoder + Dynamics Head。

预测可见 delta、事件、next latent 和 inverse action。

边界

coin flip 与抽牌预测分布；隐藏信息不作为唯一真值；攻击自动结算与对手主动行动严格分离。

状态变化

LΔ: zones, damage, energy, evolution, budgets

避免重建整份 JSON 导致模型只复制不变字段。

Latent Dynamics

F(E(st), A(at)) ≈ stopgrad(Etarget(st+1))

学习动作作用后的表示，而非人工规定卡牌价值。

Inverse Dynamics

I(E(st), E(st+1)) → action / event

迫使表示保留能够区分动作效果的信息。

策略仍未完成

Dynamics ≠ Policy ≠ Value

知道“会发生什么”不等于知道“何时值得做”。

07 · Why It Can Work

数学上是同一个条件策略函数的逐层求解

目标不是证明唯一全局最优，而是在 official engine 定义的部分可观测随机博弈中，以更好的表示和更低的每构筑样本成本优化期望终局回报。

动态输出词表

π(a | s, deck, history), a ∈ LegalOptions(s)

Pointer 直接对引擎给出的可变合法集合归一化。

共享降低样本复杂度

θshared + φdeck << θfull per deck

区域、资源、时机和动作语法跨构筑复用。

长程信用

At = GAE(rewardterminal, Vψ)

Value 将终局胜负分配到早期准备和连续操作。

稳定 / 可塑

immutable θG0 + residual φdeck + distill θG1

失败分支不污染 Foundation，成功知识按代际吸收。
