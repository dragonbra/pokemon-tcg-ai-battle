Foundation → Decoder：信息到底保留到哪里？

Executive Answer

先回答最关心的问题

没有 raw observation → decoder 的直接 residual / skip connection。

encoder 内部有很多 residual：实体残差、board + scenario residual、option + goal/scenario residual。但一旦跨过 decoder 边界，decoder 只收到最终 state [B,320]、options [B,O,320]，以及 mask / minCount / maxCount。原始 JSON、原始实体行、原始 12 字段 option tuple 都没有旁路保留。

1 × 320每个决策压缩成一个全局 state，初始化 GRU hidden。
O × 320每个合法 option 各保留一个 contextual representation。
64 events因果事件历史为固定最近窗口，更早事件只可能留在 ledger 聚合状态。
0 raw bypassdecoder 无法重新读取 encoder 压缩前的原始字段。

直接后果：如果两个策略上应区分的原始局面被冻结 encoder 映射为相同或极近的 (state, options)，任何 deck-local decoder 都无法把它们分开。反过来，如果表示仍可线性/轻量解码出关键事实，但动作仍错误，问题才更像 decoder 或训练。

Coarse Forward Pseudocode

一次决策的 forward，大致就是这样

这是为理解信息流而写的伪代码，不是可执行实现。它省略 embedding、attention、LayerNorm、FiLM 等细节，但保留了每类输入在哪一步进入、decoder 从哪里开始，以及哪些约束不走学习路径。

function policy_forward(raw_observation, registered_exact_deck, causal_memory):

    # 1. 把官方引擎给出的 raw observation 编译成结构化张量
    base = compile_board_and_legal_options(raw_observation)
      # current / players / select
      # board entities, own hand, discard, stadium, legal option[]

    causal_memory = update_causal_knowledge(
        causal_memory,
        raw_observation.logs,
        raw_observation,
        registered_exact_deck,
    )
      # recent events, own deck/prize bounds, known opponent hand

    batch = merge(
        base,
        compile_exact_deck_features(registered_exact_deck),
        compile_ledger_event_zone_hand_features(causal_memory, raw_observation),
        source_id = 0,
    )

    # 2. 冻结 Foundation：它消化所有语义输入
    board_state, base_options = frozen_board_encoder(batch)
    resources = frozen_resource_encoder(batch.registered_deck, batch.ledger)
    events    = frozen_event_encoder(batch.recent_events)
    scenario  = frozen_scenario_encoder(batch.zones, resources, events, batch.opponent_hand)

    state   = frozen_fuse_state(board_state, resources, scenario)
    options = frozen_fuse_each_option(base_options, resources, scenario)
      # state:   [1, 320]
      # options: [1, number_of_legal_options, 320]

    # ───────────────── decoder boundary ─────────────────
    # raw_observation、raw logs、raw deck tokens 不会再被直接读取

    # 3. deck-local decoder：只重排当前 options，并决定何时 STOP
    hidden = tanh(decoder_init(state))
    selected = []
    while len(selected) < batch.maxCount:
        logits = pointer_score(hidden, options)
        logits = logits + option_bias(options)
        logits = hard_mask(logits, batch.option_mask, selected)
        stop   = hard_mask(stop_head(hidden), len(selected) < batch.minCount)

        token = choose(logits + stop)       # stochastic rollout 或 greedy evaluation
        if token == STOP:
            break
        selected.append(token)              # token 是当前 raw option[] 的 index
        hidden = GRU(options[token], hidden)

    return selected                         # 例如 [3, 1]，交回官方 engine 执行

这段伪代码最值得注意的点

所有场面、卡组和历史语义都在第 2 步进入冻结 Foundation。第 3 步不会重新访问 raw observation，只对 Foundation 产出的当前 option vectors 排序。

为什么这对 review 很重要

若要让 decoder 直接重新检查某个原始事实，不能只改 GRU 或 pointer；必须新增一个明确的 decoder 输入通道，例如 raw-option adapter 或 token-memory cross-attention，并以新的版本合同审计。

function frozen_foundation_encoder(batch):

    # ── A. 通用 Transformer block：三套 encoder 都采用 Pre-LN residual ──
    function transformer_block(x, padding_mask):
        x = x + MultiHeadSelfAttention(LayerNorm(x), padding_mask)
        x = x + FFN_GELU(LayerNorm(x))
        return x

    # ── B. Board trunk：1 个 CLS + 最多 192 个 entity tokens ──
    entity = LayerNorm(
        card_id_embedding
      + owner_embedding + zone_embedding + slot_embedding
      + kind_embedding + status_embedding + parent_embedding
      + MLP(entity_numeric_5)
      + tanh(entity_semantic_gate) * ontology_semantic_320
    )

    global_token = LayerNorm(
        select_type + select_context + first_player + turn_flags
      + MLP(global_numeric_12)
      + tanh(global_zone_gate) * zone_summary
    )

    board_tokens = concat(CLS + global_token, entity)
    repeat 4 times:                         # 320 dim, 8 heads, FFN 960
        board_tokens = transformer_block(board_tokens, entity_mask)
    board_tokens = LayerNorm(board_tokens)  # TransformerEncoder final norm

    board_state    = board_tokens[CLS]
    encoded_entities = board_tokens[entities]

    # ── C. 独立 causal readers ──
    resource_tokens = LayerNorm(
        registered_card_embedding + ontology_semantics
      + deck/prize_knowledge_state + ledger_numeric_15 + multiplicity
    )

    event_tokens = concat(EVENT_SUMMARY, embed(recent_event_features_8_plus_4))
    repeat 1 time:                          # 320 dim, 8 heads, FFN 640
        event_tokens = transformer_block(event_tokens, event_mask)
    event_summary = LayerNorm(event_tokens)[EVENT_SUMMARY]

    opponent_hand_summary = LayerNorm(
        mean(known_opponent_card_embeddings) + MLP(unknown_hand_count)
    )

    goals = GoalQKV(
        query = QueryMLP(concat(board_state, each_learned_goal_role)),
        key_value = resource_tokens,
    )
      # four roles: setup / attack-prize / recovery / tempo-survival

    causal_summary = LayerNorm(
        zone_summary + event_summary + opponent_hand_summary + mean(goals)
    )

    # 第一层 state residual：把 causal summary 加回 board CLS
    state_ac = board_state
             + tanh(state_aux_gate) * causal_summary

    # ── D. 每个合法 option 先读取 board 与 goal ──
    option = LayerNorm(
        option_type + source_area + target_area + owner
      + source_card + target_card + number + source_slot + target_slot
      + option_position
      + gather(encoded_entities, source_entity_ref)
      + gather(encoded_entities, target_entity_ref)
      + tanh(option_semantic_gate) * option_ontology_semantics
    )

    board_read = CrossAttention(query=option, key_value=board_tokens)
    option = LayerNorm(option + board_read)              # attention residual
    option = LayerNorm(option + OptionFFN_GELU(option))  # FFN residual

    goal_read = CrossAttention(query=option, key_value=goals)
    option_aux = LayerNorm(goal_read + causal_summary)
    option_ac = option
              + tanh(option_aux_gate) * option_aux       # gated causal residual

    # ── E. R15 scenario bank：zones + resources + event + hand ──
    scenario_tokens = concat(
        two_zone_tokens,
        resource_tokens,
        event_summary,
        opponent_hand_summary,
    )
    scenario_tokens = LayerNorm(scenario_tokens)
    repeat 2 times:                                     # 320 dim, 8 heads, FFN 960
        scenario_tokens = transformer_block(scenario_tokens, scenario_mask)
    scenario_tokens = LayerNorm(scenario_tokens)

    scenario_summary = MLP(concat(
        mean(zone_tokens),
        mean(resource_tokens),
        event_token,
        hand_token,
    ))

    # ── F. 最终 state / option residual refinement ──
    state_read  = CrossAttention(query=state_ac, key_value=scenario_tokens)
    state_delta = FiLM(state_read, scenario_summary)
    state_scale = 2 * sigmoid(StateScaleGate(scenario_summary))
    state = LayerNorm(state_ac + state_scale * state_delta)

    option_read  = CrossAttention(query=option_ac, key_value=scenario_tokens)
    role_read    = route_each_option_to_four_goals(option_ac, goals)
    option_delta = FiLM(option_read + role_read, scenario_summary)
    option_scale = 2 * sigmoid(OptionScaleGate(option_read, scenario_summary))
    options = LayerNorm(option_ac + option_scale * option_delta)

    # source_id 固定为 0；padding persona embedding 为零，因此部署时无 persona 改动
    return state, options
Transformer block 内部 residual

x + SelfAttention(LN(x))，再做 x + FFN(LN(x))。它保留进入该 block 的 token representation。

模块融合 residual

option 读取 board、state/option 读取 causal/scenario 后，把新 evidence 加回旧 hidden representation，并常配 gate 或 scale。

不是 raw residual

所有加法左边的 x、board_state、option_ac 都已经是 learned representation；没有把原始 JSON 字段拼回最终输出。

Encoder 的真实瓶颈位置

Board 仍有逐实体 token，scenario 仍有逐 registered-card resource token；但最终 decoder API 将它们压成一个 state 和每个 option 一个向量。尤其 event 只取 summary token、opponent known hand 使用 mean、scenario family summary 使用 mean。Residual 可以缓解深层训练退化，却不能恢复这些聚合已经抹掉的细节。

Residual 的准确解释

当前 residual 是“隐藏表示保真机制”，不是“原始输入保真机制”。例如 conditioned_options = Norm(options + scale × delta) 保留的是此前已经编码过的 options，而不是原始 option 字典。LayerNorm 之后连加法尺度本身也不再原样保留。

Failure Attribution

如何判断到底坏在哪一层

当前不能仅凭 arena 输赢判断“模型忘了”。应先做表征可识别性和反事实一致性实验，把四类原因拆开。

A. 输入结构性缺失

定义：策略所需事实根本没进入 compiler，或进入字段过粗。例如 option 某个目标语义、卡文条件、进化时钟实例身份没有对应字段。

判别实验：构造只改变该事实、其他输入保持一致的 paired observations。若 compiler tensors 完全相同，缺失发生在输入/codec 层。

B. Frozen encoder 表示碰撞

定义：compiler tensors 不同，但最终 state/options 相同或 decoder 无法简单读出关键标签。

判别实验：冻结 checkpoint，保存中间张量；训练线性 probe / 小 MLP 预测 KO、攻击终止机会、进化时钟、目标 Prize value。probe 失败而原始 tensor 可判定，说明 encoder bottleneck。

C. Decoder 表达能力不足

定义：关键信息能从最终 state/options probe 出来，但单层 320 GRU pointer 无法表达需要的组合、比较或长 action-prefix 逻辑。

判别实验：保持 encoder 输出完全冻结并缓存，对同一监督集比较当前 GRU、2-layer GRU、Transformer decoder、带 raw-option adapter 的模型。只有更强 decoder 改善时才归因于容量。

D. Decoder 训练漂移 / 遗忘

定义：初始化 decoder 会做，PPO 后 decoder 不会做，而 frozen encoder hash 未变。这里遗忘只可能发生在 decoder/value，不是 encoder。

判别实验：同一 paired-state suite 对 update 0 / 中间 / 最终 checkpoint 逐点比较 logits、rank、STOP 概率和行为 KL；同时验证 encoder SHA 完全一致。

最危险的误诊

看到 PPO 后性能下降，就说“encoder 忘了”。当前代码先冻结 actor 全参数，再只开启六个 decoder component；encoder hash 还会单独计算。因此本 run 内 encoder 参数遗忘在合同上不成立。可能存在的是 Foundation 在 BC 时代就没有学会、或者 decoder 把已有信息用坏了。

另一个误诊

看到 option 有 Card ID 就认为 decoder 精确知道动作含义。Card ID embedding、ontology、source/target entity 和 scenario 已被加和、attention、FiLM、LayerNorm 多次变换；是否仍保留某个精确事实必须用 probe 或反事实测试验证，不能从代码“曾经输入过”直接推出。

Evidence Boundary

官方规则 / runtime 事实

引擎生成合法 options；攻击是终止回合提交；Supporter、手填能量、Retreat 等时机由规则和 runtime 约束。模型的 mask/min/max contract 只能保证选择格式合法，不证明策略价值。

项目模型事实 / 研究假设

320 维表示、Goal-QKV、scenario residual、decoder-only PPO 都是项目设计。它们是否足以表达强策略必须由 probe、ablation 与未修改 official-engine 对局验证。
