01 · Embedding

电脑不认识“胡地”，只认识一排数字

第一步不是思考，而是翻译：把卡牌、位置、伤害、动作类型都变成相同长度的向量。向量的每个方向可以携带一种可学习的特征。

学完你能解释：为什么所有 token 必须有同一个宽度
你已经认识的激活函数在哪里？向量先经过线性层，再经过 GELU 等激活函数。激活函数负责“弯曲”，embedding 负责先把不同信息放进同一个坐标系。
token = 类别 embedding + 数值投影 + 区域 embedding

在 0028 中，无论一个 token 来自卡牌、资源还是事件，最后都会变成 320 个数。下方只用 4 个数演示，因为 320 根柱子会看不清。

02 · Dot product

注意力的原点：两个方向是否“对得上”

点积就是把对应位置相乘再相加。方向越一致，分数越高。Transformer 用它快速判断“我现在的问题”和“哪条信息”最匹配。

学完你能亲手算出一个 attention score
[1, 2] · [3, 1] = 1×3 + 2×1 = 5
对局直觉“我能否攻击？”这个问题会与“Active 已附超能量”高度匹配，却与“弃牌区有一张 Supporter”弱匹配。不是后者没用，而是它没回答当前问题。

实验：旋转两根二维箭头

03 · Query, Key, Value

Q 提问，K 被检索，V 带回内容

同一个 token 会被投影成三种角色。Query 是它此刻想知道什么；Key 是它能被怎样找到；Value 是被找到后真正贡献的内容。

04 · Softmax

把任意分数变成总和为 100% 的注意力

点积会产生正负不限的原始分数。Softmax 把它们变成非负权重；温度越低，注意力越集中，越高则越平均。

学完你能解释：softmax 不是在判断真伪，而是在分配关注比例

05 · Multi-head attention

一个视角不够，就让 8 组注意力并行观察

每个 head 都有自己的 Q/K/V 投影，因此可以学到不同关系。它们不是人工指定的规则，但我们可以用“进化、能量、风险、目标”来建立直觉。

学完你能解释：多头不是重复计算，而是多个可学习的关系空间

选择观察视角

真实 0028 有 8 个 head，每个 head 宽 40。这里选 4 个假想视角帮助理解；训练不会给 head 手工命名。

06 · Transformer block

注意力负责交流，FFN 负责逐 token 思考

一个 block 不只有 attention。LayerNorm 稳定数值，attention 混合信息，残差保留原信号，FFN 用你熟悉的激活函数对每个 token 独立加工。

学完你能完整说出 pre-norm Transformer block 的数据流
x₁ = x + Attention(LayerNorm(x))
x₂ = x₁ + FFN(LayerNorm(x₁))
激活函数终于出现了0028 的 FFN 是 Linear(320→960) → GELU → Linear(960→320)。Attention 决定向谁取信息；GELU 帮助模型非线性地重组这些信息。

07 · Mask

看不见的、补齐的、已选过的，都必须被挡住

Mask 不是让模型“少想一点”，而是执行信息与合法性合同。被 mask 的 token 不能成为 attention key；被 mask 的动作不能成为输出。

09 · Behavior cloning

模型怎样从专家对局中学会选择

训练时，我们给模型当时可见的状态、合法 options，以及专家真实选择的有序动作。交叉熵惩罚“正确动作概率太低”，反向传播再调整 embedding、attention、FFN 与 pointer 的参数。

学完你能区分训练目标、离线模仿指标与真实对战强度
1编译状态

只保留 actor 当时可见的信息与 exact-deck conditioning。

2Teacher forcing

把专家已经选过的 prefix 喂给 decoder，预测下一步。

3交叉熵

正确 option 或 STOP 的概率越低，loss 越大。

4反向传播

梯度穿过 pointer、cross-attention 和 state memory。

loss = −log P(专家下一动作 | 状态, 已选 prefix)
高标准结论exact-action accuracy 高，只能证明“更像老师”。真正的策略强度必须在未修改的官方 engine runtime 中，用冻结对手、seed 与先后手合同进行真实对局评测。

结课 · Retrieval before decision

你现在已经能读懂一条 Transformer 决策链

最后做 3 道题。它们不考术语记忆，只检查你是否抓住了信息流。

1. 在 attention 中，谁表达“我现在想找什么”？
2. 0028 的一个合法动作怎样利用全场信息？
3. validation exact-action 很高，能直接证明模型对战更强吗？
选择答案后检查。满分不是终点；能把答案讲给别人听，才是真的会了。

一句话讲 Attention

用 Q 与 K 算相关度，再按权重汇总 V。

一句话讲 Transformer

Attention 交流，FFN 思考，残差保真，LayerNorm 稳定。

一句话讲 0028

状态成为 memory，动作读取全场，pointer 依序选择并 STOP。
