# 0042 Champion G1 Full-55 CUDA-2048 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Seal V22 update 10 as the user-designated Champion G1 and evaluate the same immutable model from all 55 exact-deck focal views against independent Frozen Policy-0809, publishing canonical Combat Mat HTML.

**Architecture:** A project-local controller waits for complete V22 U10 terminal evidence, copies and hashes the model-only checkpoint into a Champion G1 archive, and produces a reference FP16-storage/FP32-runtime package. It then runs the existing 0042 custom-deck CUDA-2048 evaluator in isolated subprocesses, renders every detail through the canonical Policy-0809 report UI, and atomically refreshes the durable Combat Mat index after each completed deck. Completed raw reports are the restart boundary.

**Tech Stack:** Python 3.11, PyTorch CUDA resident collector, systemd user service, existing 0042 candidate materializer, `evaluation.reporting`/Combat Mat publication contracts.

## Global Constraints

- Source checkpoint is exactly `V22_archaludon_ex_cinderace_048/checkpoint/update-000010.pt` with matching sidecar and complete U10 CUDA-2048 evidence.
- Champion and Frozen opponent are independent; Frozen opponent resolves to full immutable Policy-0809.
- Every focal deployment is full-effective weights → FP16 storage → strict FP32 runtime and binds one exact 60-card deck.
- First phase is the first numbered deck for each formal class 0-13; class-14 Other and all repeated classes run in phase two.
- Each deck receives 2,048 official CUDA-engine games; incomplete/error/semantic-fallback results are rejected.
- Durable output uses the existing Combat Mat index/detail visual language and passes `evaluation.combat_mat_contract`.
- Numeric-closeness diagnostics do not gate training or evaluation; identity and semantic/action checks remain mandatory.
