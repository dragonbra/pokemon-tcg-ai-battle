# Frozen-0806 Arena Pool Implementation Plan

**Goal:** Build one immutable 256-game exact-deck distribution that is shared by Arena validation, PPO rollout batches, and final frozen evaluation.

**Contract:** The schedule contains 240 games allocated from the 2026-08-06 Top 100 exact decks and 16 explicitly selected games from ranks 101-500. Opponents use Policy-0019; the evaluated/main policy uses Policy-0806. Runtime code consumes committed integer counts and never recomputes or randomly resamples the distribution.

**Evidence boundary:** This task materializes and validates deck/schedule assets only. It does not run games, make policy-strength claims, change the default Frozen-0019 catalog, or modify the official engine.
