> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Evaluate the 0042 V1 update-140 source checkpoint as a raw-FP32 diagnostic on the canonical CUDA-2048 schedule with exact focal deck 007 and full frozen Policy-0809 opponents.

**Architecture:** Reuse the project-local complete-candidate exporter to materialize every deployed tensor in FP32, then strict-load that package into FP32 CUDA runtime tensors. Persist only a temporary JSON report under `.tmp/evaluation/`, explicitly marked ineligible for Kaggle, Frozen Promote, or package-strength evidence.

**Tech Stack:** Python 3.11, PyTorch CUDA, the repository's official CUDA engine runtime, 0042 policy materialization and Frozen-0809 schedule code.
