# 0043 Benchmark V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish and implement a reproducible CUDA-2048 benchmark whose fixed opponent is `(exact deck 001–067, Champion-G2)` and whose schedule is balanced across represented Meta Archetypes.

**Architecture:** A versioned schedule materializer allocates 2,048 games as evenly as possible across the 28 non-empty `own_archetypes_v2` reporting classes, then evenly and seed-randomly across exact decks inside each class. A generic evaluator strict-loads a focal checkpoint with Kaggle FP16-storage/FP32-runtime semantics, holds one immutable G2 model resident, injects exact opponent own-deck IDs per lane, and emits a self-contained report under `docs/evaluation/combat_mat/benchmark_v1/<focal-candidate>/`.

**Tech Stack:** Python 3, PyTorch, CUDA Engine 2.0, JSON manifests, static HTML/CSS/JavaScript, pytest.

## Global Constraints

- Every benchmark contains exactly 2,048 official CUDA Engine 2.0 games and all must be terminal with zero error, routing failure, unfinished game, or feature D2H fallback.
- Every opponent identity is the fixed pair `(deck_i, Champion-G2)`; no other policy may enter the schedule.
- Sample only exact immutable decks `001`–`067`; hashes and archetype names remain metadata rather than identities.
- Balance the 28 non-empty V2 Meta classes to 73 or 74 games each, then balance member decks within each class to a maximum count difference of one.
- Display all 29 classes; class 14 `Other` has no registered deck and must display `n=0`, never a fabricated 0% win rate.
- Use `kaggle_fp16_storage_fp32_runtime_v1` for focal checkpoint strength evidence and strict immutable G2 FP16-storage/FP32-runtime loading.
- Preserve seeded toss winner → Agent context-41 first/second choice, unique engine/search/policy seeds, and exact deck/policy routing audits.
- Do not modify `engine/source/`, Champion-G1, Champion-G2, Policy-0809, or historical evaluation reports.
