> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Evaluate an explicitly cheating Deck-007 oracle that reads the opponent's exact 29-way Meta class and routes only the focal LoRA/Action Decoder/Allocation Head among U40, U90, U200, and U282 while sharing one immutable semantic backbone.

**Architecture:** Materialize all four checkpoints through `kaggle_fp16_storage_fp32_runtime_v1`, prove their frozen Actor tensors are exactly equal after excluding the three intended routed modules, and keep the U282 Actor/Critic as the shared runtime. Partition the immutable Benchmark V2 jobs using an audited `if/elif` Meta router, activate one resident head bundle per partition, run each partition through the existing CUDA collector, and scatter episodes back into schedule order. Register the result as `Experimental-Oracle-MetaRouter-V1`, never as Frozen/Promote/Kaggle evidence.

**Tech Stack:** Python 3, PyTorch, project-local CUDA Engine 2.0, official-engine Benchmark V2 schedule, pytest, static HTML.

## Global Constraints

- Do not modify `engine/source/`.
- Opponent remains complete immutable `Policy-0809` with its existing effective identity.
- Route is exact: `06/08/10/27 -> U200`, `01/02/17 -> U40`, `03 -> U90`, all other Meta including `00/04/05 -> U282`.
- Only Policy Q/V LoRA, Action Decoder, and Allocation Head may differ across routes; every declared shared tensor must compare exactly equal.
- All four source checkpoints must be materialized as FP16 storage then strict-loaded FP32 runtime before head extraction.
- Oracle access to the opponent's exact deck/Meta must be disclosed in the manifest and report; result is diagnostic only.
- Preserve the 2,048-game Policy-0809 Benchmark V2 common-random schedule and official first-player contract.
- Create a new V9 report rather than overwriting the published V8 formal snapshot.
