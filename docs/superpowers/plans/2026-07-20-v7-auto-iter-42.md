# V7 AutoIter Iteration 42 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 从 `iter-41` 的真实 full-trace 中定位一个可归因的策略失败，并以固定 `deck.csv` 为前提完成一个可验证的单变量改进实验。

**Architecture:** 先把原始 trace 的局面与当前决策还原为轻量 case，再由独立 advisor 复核规则和卡牌语义。只有存在明确的“当前合法动作—预期动作”差异时，才在 `main.py` 中做最小改动，并用回归测试和同规模评测比较 control/candidate；没有证据时保留当前策略并记录 observe。

**Tech Stack:** Python 3.11、现有 `pytest` 测试、`scripts/alakazam_auto_iter.py`、外部 `ptcg-agent-kaggle` trace/report。

## Global Constraints

- 固定 `submission/alakazam_v7_auto_iter/deck.csv`，不得修改卡组。
- 不提交 Kaggle；本轮只做本地评测和报告记录。
- 完整 raw trace 保存在 repo 外，只保留最新一轮；迭代文档、指标、case 和 decision 文档保留在 repo。
- 每轮记录改动、control/candidate 指标、advisor 结论、`accept/observe/reject` 和 best 是否更新。
- 优先关注第二回合 `Powerful Hand`、post-KO ready attacker/bench relay、胜率及 action error；不能用单一指标替代胜率。
