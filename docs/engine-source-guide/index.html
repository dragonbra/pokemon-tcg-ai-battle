Card Execution IR

文本只展示；真正执行的是 typed records

CardMaster
├─ identity / card class / tags
├─ Pokémon stats / evolution
├─ Skill* ability
├─ Skill* play
├─ Skill* delay
└─ Attack* attacks[]

Attack
├─ energy cost + base damage
├─ preEffects[]
└─ postEffects[]
Effect
├─ EffectType opcode
├─ values[2]
├─ Target
│  ├─ TargetPlayer
│  ├─ AreaType[]
│  └─ TargetCondition[]
├─ ConditionType
├─ EffectSelectType / SelectContext
└─ loop / random / ownership flags
Attack / Ability / Trainer / Stadium 最终都在 Skill/Effect 层汇合。

差异主要来自主阶段合法性、Skill 的有效 area、trigger timing 与卡牌所在 zone 的生命周期；并不是四套互不相干的执行器。

Setup

洗牌、先后手、起手、mulligan、Active/Bench、Prize。

TurnStart

轮转 timed state 与 history，牌库失败检查，抽 1。

Main

每次从当前 state 重新生成所有合法 Play/Attach/Evolve/Ability/Retreat/Attack/End。

Commit

Attack 走 pre-effect、伤害、post-effect、trigger/KO 后直接结束回合。

Refresh

重算持续效果，校验 bench/tool，处理 trigger 与 KO。

Checkup

Poison/Burn/Asleep/Paralyzed 与 checkup trigger。

Win check

Prize、无 Pokémon、回合开始无法抽牌。

Next turn

清 turn-local flags，切换 active player。

Visibility Boundary

内部全知 State、observation 和 search state 是三层边界

Engine truth

双方完整 hand/deck/Prize、RNG 与所有实体状态。

Observation JSON

公开区完整；对手 hand 为 null；Prize identity 隐藏；deck 通常只有 count。

Sanitized blob

erasePlayerData 清除不应直接获得的 card identity，再序列化 continuation。

Search hypothesis

调用者显式提供未知 zone 假设，Search 填充 clone 后再分支。

模型不能因为 engine 内部有真值就读取它。

actor-visible feature 只能来自 JSON 当下可见字段与因果历史；binary search state 也经过独立的隐藏信息裁剪。
