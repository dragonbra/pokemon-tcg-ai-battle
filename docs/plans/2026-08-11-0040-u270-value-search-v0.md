# 0040 U270 Value Search V0 Implementation Plan

## Goal

Run a paired official-CPU 256-game A/B experiment for the exact 0040 update-270
policy.  The treatment is a policy-conditioned local reranker over only the six
Phase 3 audited one-step decision shapes.  It uses the update-270 critic and may
override the actor's target/resource selection.  The control remains byte-level
equivalent to the existing actor-only path.

## Locked Assets

- RL checkpoint: `rl_runs/0040_dragapult_0809_action_boundary_rl/versions/V2_snapshot_loader_fix_long_run/checkpoint/update-000270.pt`
- Portable source package: `.tmp/evaluation/0040_u270_cpu256_after_reboot/package`
- Focal deck: `dragapult_ex_07bedfffbfad`
- Opponent policy: canonical complete Policy-0806 from the repaired resolver
- CPU schedule: Frozen-0806 v3 replica 0, seed `341512806`, 256 exact slots
- Engine: unmodified official CPU runtime from `engine/source/ptcgProgram 22/`

The update-270 checkpoint contains the effective actor deltas and the paired
update-270 `value_head.*` tensors.  A newly exported portable artifact must retain
the same effective-weight identity and FP16-storage/FP32-runtime contract.

## Implementation Boundary

1. Add a tested `OnlineCausalEncoder.fork()` that independently copies every
   mutable `CausalKnowledge` field while sharing immutable configuration and
   prototype metadata.
2. Add an evaluation-only `value_search_v0` package under project 0040.  It owns
   exact handler-shape eligibility, policy-conditioned candidate grouping,
   nonprivileged hidden hypotheses, official Search lifecycle, invariant checks,
   result logging, and aggregation.
3. Extend the 0040 experimental inference server protocol with a branch-value
   request.  It forks the current session encoder once per sibling branch,
   collates all branch batches, and performs one update-270 Value forward.
4. Add an opt-in evaluation worker hook.  The default is off and the existing
   policy action is returned unchanged unless all V0 checks pass.  Every runtime
   error or unknown shape falls back to that original action.
5. Persist one JSONL record per eligible/rejected search attempt and retain timing
   counters separately from normal policy inference.

## Enabled Shapes

- Main/Main Basic-to-Bench placement, grouped only after the actor chose Play Basic.
- Main/Main manual Energy attachment, same source Energy and alternate targets only.
- Energy/DiscardEnergy retreat payment with exactly one selected Energy and at
  least two legal alternatives.
- Card/Switch own target only for the audited retreat continuation shape.
- Card/Switch opponent target only for the audited focal-owned Boss-like handler.
- Card/AttachFrom visible attached-resource destination only for the audited
  Energy Switch handler.

All other decisions are unknown and remain actor-only.  Attack, End, Evolve,
draw/search/shuffle/coin/random paths, terminal/turn-changing/opponent-owned
branches, forced nodes, and multi-step resolution are hard rejects.

## Nonprivileged Determinization

Search roots are reconstructed without accessing the live omniscient opponent
package, deck, hand, prize, or deck order.  Own hidden counts are deterministically
allocated from the focal registered deck minus visible identities.  Opponent
unknown slots use fixed public legal placeholder identities derived without
opponent-specific input.  Enabled transitions must remain feature-invariant under
a second public placeholder hypothesis; otherwise the decision falls back.

## Verification

- Fork isolation and sibling isolation.
- Search-vs-equivalent-live DecisionBatch and update-270 Value exact parity.
- Hidden-hypothesis perturbation invariance for every enabled shape.
- Hidden-sensitive Draw remains rejected.
- Policy-conditioned grouping cannot cross semantic families.
- Search branch winner maps exactly to the original live selection vector.
- New code with the switch off reproduces the canonical baseline manifest and
  per-game results.
- Both 256-game runs use identical game IDs, opponent slots, engine/policy/search
  seeds, toss results, and agent-selected seat contract.

## Outputs

The run produces immutable A/B summaries, the paired per-game matrix, search
decision JSONL, family/reject/timing aggregates, representative disagreements,
and a Phase 4 report.  The 0040 DESIGN Markdown and HTML are synchronized with the
evaluation-only action-selection experiment and remain explicit that production
inference defaults to actor-only.
